# 政府资金申请报告（gov-fund-application）

**依据的真实文件**（2025-2026，skill 内嵌规则均出自这些文件）：
中山市住建局《超长期特别国债支持住宅老旧电梯更新项目补贴资金申请指引（企业版）》；
莒南县《超长期特别国债资金加力扩围支持设备更新项目申报》通知；
发改委资金申请报告编制要点（8 章结构）；扬州邗江"两重"资金申请报告编制成交公告（市场行情 2.1 万元/30 天）。

**重要前提**：资金申请报告全国**无统一模板**，各省市发改委每年发年度申报通知/编制指南。
本 skill 给通用骨架 + 硬规则；**动手前必须先查当年度属地发改部门的最新申报通知**，
以其为准覆盖本 skill 的默认值（尤其支持领域、投资门槛、补助比例、截止时间）。

## 总工作流（6 步，Step 5 是硬门）

```
Step 0 渠道判定 → Step 1 项目体检 → Step 2 政策对照 → Step 3 报告撰写
     → Step 4 材料包组装 → Step 5 质量门(⛔report_check.py) → Step 6 交付
```

## Step 0 — 渠道与领域判定

向用户确认（一次问全）：
1. **资金渠道**：超长期特别国债（"两重"建设 / "两新"设备更新）/ 中央预算内投资 / 地方政府专项债——三者申报系统、格式、比例不同
2. **年度批次**：当年常规批 / 提前批（次年）
3. **投向领域**：对照当年度支持领域清单（设备更新类常见：工业重点领域、用能设备、能源电力、交通运输、物流设施、环境基础设施、老旧电梯等民生领域）
4. **项目基本信息**：项目名称（须与审批文件完全一致）、项目代码、总投资、拟申请额度

## Step 1 — 项目体检（报不了就早说）

按莒南通知 6 条硬要求逐项核对，给出红/黄/绿结论：

| # | 要求 | 缺项处理 |
|---|---|---|
| 1 | 符合支持方向，**不得含**房地产开发、楼堂馆所、形象工程、政绩工程 | 直接劝退 |
| 2 | 前期手续齐全：审批（核准/备案）、城乡规划、用地（用海）、环评、节能审查；无需办理的要有部门说明 | 缺项但急需：县级政府或行业部门出**书面承诺函**＋完成时间表＋责任人 |
| 3 | **资金闭合**：各渠道资金相加＝总投资；每渠道有证明（财政性资金→政府/财政到位承诺函＋是否新增地方政府债务；自有资金→银行存款证明；已有专项债的→证明，且专项债+国债 ≤ 总投资） | 硬伤，必须补 |
| 4 | 不得重复申报：已获中央财政投资或其他部门支持的原则上不再报；不得多头申报、不得在多个投向重复报送 | 核查后如实披露 |
| 5 | 列入严重失信主体名单或安全生产严重失信名单的单位不得申报 | 信用中国核查 |
| 6 | 涉及证明的部门：住建、生态环境、自规、审批、发改、财政 | 提前对接 |

## Step 2 — 政策对照（分领域门槛与比例）

设备更新类常见标准（**以当年度属地通知为准**，下表为 2025 莒南通知口径，用作默认）：

| 领域 | 投资门槛 | 补助比例上限 |
|---|---|---|
| 工业重点领域设备更新 | 总投资 ≥2000 万 | 15% |
| 用能设备更新改造 | 节能量 ≥50 万 kWh/年 或 150 吨标煤；能效 2 级+ | 20% |
| 能源电力设施设备（风电光伏改造） | ≥2000 万（配电网 ≥1 亿） | 15% |
| 老旧营运船舶报废更新 | 无 | 按吨补贴（报废 1000 元/总吨档；报废+新建 1500-3200；新建新能源 1000-2200） |
| 物流设施设备更新 | ≥2000 万 | 30%（中央储备粮棉糖直属库 ≤70%） |
| 环境基础设施提标改造（垃圾焚烧/污水） | ≥3000 万 / ≥5000 万 | 60%，单项 ≤1 亿 |

**中央资金申请比例**通用红线：分领域不同，编制要点提示一般**不超过核算投资的 80%**；报告里必须写明测算口径。

## Step 3 — 报告撰写（八章标准骨架）

按 `templates/报告骨架模板.md` 逐章写，各章要点（来自编制要点）：

1. **项目概况**：名称与审批文件一致、建设内容明确具体（禁"等相关项目"）、总投资与可研批复一致（调整要说明原因）、申请额度占比如实
2. **项目背景与必要性**：紧扣当年度政策与支持领域（引用最新文件名）；用行业数据/缺口数据/需求预测说话；论证出"非建不可"；**政策表述转化为项目具体需求**，不整段抄文件
3. **项目符合性与建设条件**：逐条对照投向领域文字；用地、能评、环评等条件落实情况
4. **建设方案**：技术/设备/工程/建设管理方案；设备方案列主要设备清单
5. **投资估算与资金筹措**：估算有依据（行业定额、市场价、同类项目造价）；分项费用构成；预备费 ≤5%；资金筹措写明每渠道来源与到位安排
6. **项目实施进度**：工期安排、年度投资计划、关键节点（开工/完工时限按国债管理要求——获批项目须限期开工、次年年底前完工，属地通知为准）
7. **绩效目标**：四件套——产出效益（规模/产能/服务人数）、经济效益（收入/利润/税）、**碳减排效益（2026 年起新增必填）**、满意度效益；全部可量化、可考核，禁"明显提升"
8. **风险评估与防控**：风险识别、等级评估、防控措施

## Step 4 — 附件材料包组装

标准材料清单（模板在 `templates/`，按属地通知增删）：
申请书（按申报主体分实际出资/非实际出资两个版本）、前期手续复印件（备案证/规划/用地/环评/节能）、
资金证明（承诺函/存款证明/贷款意向）、项目情况表、主要设备清单、开工/完工佐证。
注意：非实际出资单位作为申报主体时，须提供**实际出资单位账户**作国债收款账户＋出资佐证。

## Step 5 — 质量门 ⛔ 不能跳

```bash
python <skill目录>/scripts/report_check.py <报告.md或目录>
```

硬校验（任一 error 即 exit 1）：
1. 八章必备章节齐全（标题匹配）
2. **资金闭合**：报告文本中"总投资"与各渠道金额之和一致（正则抽取万元数校验，±0.5% 容差）
3. 申请额度 ≤ 对应领域比例上限（从报告识别领域，对照内嵌表；识别不出按 80% 提醒）
4. 绩效目标章含：产出、经济、**碳减排**、满意度四类关键词
5. 空洞表述黑名单（warning 级）：无数据支撑的"进一步加强/有效提升/持续推进/不断完善"
6. 预备费 ≤5% 提醒；"等相关项目/等类似项目"模糊表述 → error

## Step 6 — 交付

- 报告正文（docx/md）+ 自评估报告提示（"两重"项目常要求**资金申请报告＋项目自评估报告**双件套，同步准备）
- 材料清单核对表（每项标 已备/待补/找哪个部门）
- 市场行情参考：第三方编制报价约 2.1 万元/份、工期 30 天（2025 扬州邗江真实成交，含自评估报告）
- 收尾提示：线上（国家重大建设项目库）+ 线下（正式申报文件）双线并行报送

## 边界

- 不替用户编造数据：投资、节能量、碳减排等必须有用户提供的依据；没有就标注【待补：依据】
- 年度政策时效性强：默认值仅兜底，**属地当年度通知永远优先**
- 不做"包过"承诺；退回风险在 Step 1/5 如实披露
