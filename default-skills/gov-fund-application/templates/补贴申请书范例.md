# 补贴/资金申请书范例（改造自中山市官方指引附件1，两个版本）

## 版本A：申报主体＝实际出资单位

```
致：xx县（市、区）发展和改革局／xx镇人民政府（街道办事处）

    由我公司（申报单位名称）负责组织申报超长期特别国债的xx街道（镇）
xx项目（项目代码：xxxxxxxx）已完成前期审批手续，总投资 xx 万元，其中拟申请
超长期特别国债资金共 xx 万元（占核算投资 xx%，符合当年度 xx 领域支持比例）。
项目计划于 20XX 年 X 月开工，20XX 年 X 月完工。
    现向你部门提出资金申请，并提交以下材料（见附件）：

    1. 项目资金申请报告（正文八章）；
    2. 项目审批（核准/备案）文件；
    3. 规划、用地、环评、节能审查等前期手续（或无需办理说明）；
    4. 资金证明材料（存款证明/贷款意向/政府到位承诺函）；
    5. 主要设备清单及定价依据；
    6. 项目情况表；
    7. 其他按当年度申报通知要求的材料。

    国债资金收款账户：
        户　名：
        开户行：
        账　号：

    我公司承诺所提供的文件、证件及材料真实、合法、有效，绝无弄虚作假，
并为此承担全部法律责任和后果；将严格按照规定使用该笔资金，专款专用，
接受资金监管和绩效评价。

                                        申报单位（盖章）
                                        20XX 年 X 月 X 日
```

## 版本B：申报主体＝非实际出资单位（物业、平台公司等）

在版本A基础上，正文增加一段并调整收款账户：

```
    完成本项目的实际出资单位为 xxx 公司（统一社会信用代码：xxxxxxxx），
请将国债资金拨付至实际出资单位指定账户：
        户　名：（实际出资单位）
        开户行：
        账　号：
    并附：出资协议/合同、出资佐证材料。
```

## 使用注意（源自官方指引）

1. **收款账户铁律**：资金必须拨付至**实际出资单位**账户；物业等非实际出资主体
   作为申报单位的，必须提供实际出资单位账户＋出资佐证
2. 两版本承诺条款不可删减（真实性承诺＋专款专用承诺是审核必看项）
3. 随申请书一般还需：项目情况表、验收表（完工后拨付类项目），按属地附件格式
4. 主管部门咨询电话在属地通知附件中，报送前先电话核对材料清单版本
