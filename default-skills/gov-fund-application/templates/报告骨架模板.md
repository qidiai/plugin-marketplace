# 资金申请报告骨架模板（八章标准结构）

> 依据：国家发展改革委资金申请报告编制要求（通用口径）。
> 使用：整篇复制后逐节替换【】占位；每节下方的"硬要求"不要删除，写完再删。

---

# 【项目名称】资金申请报告

（申报单位盖章、编制日期；随附：申报单位营业执照、前期手续复印件等，见材料清单）

## 一、项目概况

- 项目名称：【与审批（核准/备案）文件完全一致】
- 项目代码：【全国投资项目在线审批监管平台代码】
- 建设单位：【全称＋统一社会信用代码】
- 建设地点：【省/市/县＋具体地址】
- 建设内容与规模：【明确具体：建（构）筑物面积、设备台（套）数、处理能力等量化表述】
- 建设工期：【开工年月—完工年月】
- 总投资及资金来源：总投资【X】万元，其中：【银行贷款 X＋企业自有 X＋拟申请超长期特别国债 X＋其他 X】（四者相加必须等于总投资）

> 硬要求：①名称与审批文件一致，不得擅自变更；②建设内容禁止"等相关项目"模糊表述；③总投资与可研批复一致，如有调整必须说明原因；④申请额度写明测算口径。

## 二、项目背景与必要性

2.1 政策背景：【引用当年度最新政策文件全名＋文号，落到本项目领域的具体条款】
2.2 行业现状与问题：【用数据：行业缺口、能耗/排放现状、服务能力缺口】
2.3 项目建设必要性与紧迫性：【论证"非建不可"：不改不行的硬约束（标准强制/安全/产能/民生）】

> 硬要求：政策背景必须转化为本项目具体需求，禁止整段摘抄政策文件。

## 三、项目符合性与建设条件

3.1 符合性：逐条对照当年度申报通知的投向领域文字，逐句呼应
3.2 前期手续：审批（核准/备案）【文号】、规划【文号】、用地【文号】、环评【文号】、节能审查【文号】；无需办理的附部门说明；手续在办的附承诺函＋时间表＋责任人
3.3 建设条件：用地落实、水电汽配套、原材料供应、施工条件

## 四、建设方案

4.1 技术方案：【工艺路线及技术来源，对标行业先进水平】
4.2 设备方案：【主要设备清单：名称/规格/数量/能效等级——用能设备必须写能效等级（≥2级）】
4.3 工程方案：【建（构）筑物、总图运输、公用工程】
4.4 建设管理方案：【项目法人责任制、招标方案、监理安排】

## 五、投资估算与资金筹措

5.1 投资估算：【估算依据：行业定额/市场价格/近期同类项目造价；分项：建筑工程费、设备购置费（附主要设备清单及定价依据）、安装费、工程建设其他费用（取费标准合规）、预备费（≤5%）、建设期利息】
5.2 分年度投资计划：【第1年 X 万元、第2年 X 万元…】
5.3 资金筹措：
- 企业自有资金【X】万元（银行存款证明）
- 银行贷款【X】万元（贷款意向书/授信）
- 拟申请超长期特别国债【X】万元（占核算投资 X%，符合领域上限）
- 其他渠道【X】万元（已获专项债的：列明金额，确保专项债＋国债 ≤ 总投资）

> 硬要求：①每项费用有依据；②预备费比例不超过 5%；③各渠道资金相加＝总投资；④地方财政性资金需政府/财政部门到位承诺函并注明是否新增地方政府债务。

## 六、项目实施进度

6.1 建设工期：【关键节点：开工、设备到货、安装调试、竣工验收】
6.2 当前进展：【已完成的前期工作、已签合同、已支付款项】
6.3 年度实施安排：【获批后限期开工（当年度内），按属地通知确保完工时限】

## 七、绩效目标（四件套，全部可量化可考核）

| 类别 | 指标 | 目标值 | 考核方式 |
|---|---|---|---|
| 产出效益 | 更新设备 X 台套 / 建成能力 X | 【】 | 验收报告 |
| 经济效益 | 年新增收入/利润/税收 | 【】 | 财务报表 |
| 碳减排效益 | 年节能量 X 吨标煤 / 年减碳 X 吨（2026 年起必填） | 【】 | 节能量审核/碳核算 |
| 满意度效益 | 服务对象满意度 ≥【】% | 【】 | 第三方调查 |

> 硬要求：禁止"明显提升/显著改善"等不可考核表述。

## 八、风险评估与防控

8.1 风险识别与等级：【市场风险/技术风险/资金风险/建设风险，高中低】
8.2 防控措施：【对应每项风险的具体措施与责任安排】

# 附件清单（随报告装订）

1. 前期手续：备案证/核准文件、规划、用地、环评、节能审查（或无需办理说明/承诺函）
2. 资金证明：存款证明、贷款意向、政府到位承诺函
3. 主要设备清单（含能效等级、定价依据）
4. 项目情况表（按属地通知格式）
5. 申报单位资质材料
6. 已获其他资金支持的说明（防多头申报核查）
