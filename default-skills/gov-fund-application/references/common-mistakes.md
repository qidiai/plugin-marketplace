# 常见退回错误清单（编制要点 + 官方审核关注点）

## 一、五大高频退回错误

| # | 错误 | 典型表现 | 纠正 |
|---|---|---|---|
| 1 | **项目名称与审批文件不一致** | 审批文件为 A 项目，申报时改叫 B 项目 | 名称逐字对齐审批（核准/备案）文件 |
| 2 | **建设内容与可研不符** | 申报建设内容超出可研批复范围 | 建设内容锚定可研；确需调整先变更批复 |
| 3 | **投资估算无依据** | 关键设备无询价、取费无标准 | 行业定额＋市场价＋同类项目造价；设备列清单附定价依据 |
| 4 | **资金来源不实** | 配套资金只写"企业自筹"无存款证明；无贷款意向函 | 每渠道挂证明文件；财政资金挂到位承诺函 |
| 5 | **绩效目标空洞** | "效益显著提升""管理水平进一步提高" | 四件套指标全部量化＋写考核方式 |

## 二、章节级易错点

- **项目概况**：总投资与可研批复不一致且无调整说明；申请额度无测算口径
- **背景必要性**：大段摘抄政策文件不落到项目需求；数据陈旧（政策引用必须是当年度最新）
- **符合性**：只写"符合XX领域"却不逐句对照申报通知原文；漏写无需办理手续的部门说明
- **建设方案**：用能设备不写能效等级（审核硬看 ≥2 级）；设备清单与投资估算的设备费对不上
- **资金筹措**：专项债＋国债之和超总投资（红线）；预备费 >5%
- **实施进度**：与国债时限要求冲突（获批年内必须开工、次年年底前完工）
- **绩效目标**：2026 年起缺碳减排效益直接退

## 三、文风红线（写给 AI 生成场景）

- 全文禁止：等类似项目 / 等相关项目 / 进一步加强 / 有效提升 / 持续推进 / 不断完善（无数据支撑时）
- 政策引用必须写全文件名＋文号，不用"国家有关规定"这种模糊指代
- 数字必须带单位与口径（"投资 25000 万元"而非"投资 2.5 亿左右"）
- 承诺类条款（真实性承诺、专款专用承诺）是审核必看项，不可省略
