# 申报硬要求与分领域标准（真实文件汇编）

> 来源：①莒南县《超长期特别国债资金加力扩围支持设备更新项目申报》通知（2025）；
> ②中山市住建局官方申请指引（企业版）；③扬州邗江"两重"项目成交公告。
> 免责：各省市年度口径不同，属地当年度通知永远优先。

## 一、申报硬要求（六条，全部来自官方申报通知原文口径）

1. **符合支持方向**：不得含有房地产开发、楼堂馆所、形象工程和政绩工程等国家政策限制或禁止性内容
2. **手续齐全**：审批（核准、备案）、城乡规划、用地（用海）审批、环评、节能审查等前期手续完备；
   无需办理的手续需相关部门出具说明。对已完成审批但缺部分手续的急需项目，由县级人民政府或
   行业部门出具**开工前完成手续办理的书面承诺函**，附各项前期工作完成时间表和责任人
3. **资金完整闭合**：各渠道资金相加＝总投资，每渠道有证明：
   - 地方财政性建设资金 → 当地政府或财政部门出具**资金到位承诺函**，并明确是否增加地方政府债务
   - 企业自有资金 → 银行存款等证明材料
   - 已获专项债项目 → 提供证明，且专项债＋拟申请国债 ≤ 项目总投资
4. **不得重复申报**：已获中央财政投资或其他部门支持的原则上不得重复申报；不得多头申报；
   同一项目不得在多个投向重复报送（正确选填投向领域）
5. **失信受限**：列入严重失信主体名单或安全生产严重失信主体名单的单位不得申报
6. **证明出具部门**：住建局、生态环境局、自规局、审批局、发改局、财政局

## 三、项目管理标准（中山官方指引口径）

- **开工认定**（满足其一，需佐证）：①设备合同签订＋首付已付＋电梯进入生产（厂家书面证明）；
  ②合同＋首付＋特种设备施工告知手续；③合同＋首付＋实际施工（现场照片）
- **完工标准**：确定使用管理人与维保单位、通过监督检验并取得使用登记证；完工期限以国家及省年度通知为准
- **时限铁律**：2025 年获批项目必须年内开工，所有项目 2026 年底前完工
- **资金拨付**：经住建/发改/市场监管联合验收后拨付；资金必须拨付至**实际出资单位**账户
  （物业等代申报的须提供实际出资方账户＋出资佐证发票）
