# 表演锚定（Persona Anchor）

来源：OnlyShot `character-design.md`（阶段 3 设定圣经）+ shuohao `novel-characters` 卡片字段。

## 5 特写人格锚定

业界硬数据：主角需要 **5 个特写镜头**完成人格锚定，且必须在前 3 分钟
（第 1 集前 60 grid 内）出现。每个核心角色列出第 1 集展示其性格的 5 个特写：

```
特写 1：<动作> — 展示「核心标签」
  例：摸颈上红丝带（标志动作 → 冷静）
特写 2：<动作> — 展示「反差点」
  例：笑着递咖啡，转身眼神瞬间冷下来（表里不一）
特写 3：<动作> — 展示「标志性能力」
  例：一眼看穿合同陷阱（法律敏锐）
特写 4：<动作> — 展示「情感软肋」
  例：盯着童年照片走神（失去亲人）
特写 5：<动作> — 展示「决心或目标」
  例：撕掉合同：「这次，换我」（复仇）
```

## 角色档案必填项

- **原型 + 反差点**：一句话，必须有（没有反差点的角色先不做卡）
- **视觉母题 ≥2**：反复出现的色彩 / 物件 / 动作 / 配饰
- **标志性动作 ≥2**
- **口头禅 ≥3 句**（进 voice.catchphrases，对接 TTS）
- **服装表按阶段**：变体，不是新身份——进 variants[]，生效集数写清

## 与看卡层的关系

表演锚定是"怎么演"，看卡层是"长什么样"。分镜 skill 从这里取特写清单安排镜头，
从看卡层取锚点与锁面画人。两层都挂在同一张卡上，改哪层都先改卡。
