# 设定图（Ref Sheet）版面规范

来源：shuohao-skills `novel-characters` Step 8 + OnlyShot `storyboard-frame-industrial.md`。

## 默认版面：16:9 三区 sheet

```
┌──────────┬────────────────────────────┐
│  半身像   │   正视    侧视    背视       │
│ （证件照） ├────────────────────────────┤
│  面部基准  │  细节 · 细节 · 细节 · 细节   │
│   ~34%   │            16:9            │
└──────────┴────────────────────────────┘
```

- **左栏半身像**：面部设计基准，右上三视图的脸照它画
- **右下细节条**：关键细节小特写（眼睛 / 配饰 / 鞋 / 手持道具）

## 竖屏替代版面：9:16 单人卡

分镜首帧直接用单人半身像时用（漫剧常见）：

```
上半：全身正视（比例优先）
下半：面部特写 + 2 个细节特写
```

## 两条硬要求（出图后必查）

1. **三视图的脸必须与半身像一致**——否则一张图两个长相，一致性直接报废
2. **全身像比例协调**——模型会为塞下细节把人压扁（4 头身以下=失败）

## 调用规矩

- 一个角色一次调用，绝不批量
- 图已存在（`images/<slug>-sheet.png`）→ 跳过，断点续跑
- 单个失败跳过不阻断，最后汇总说明
- 出完必须给用户过目：脸型 / 服装 / 氛围，不对改 prompt 重跑
