# 连续性锁（Continuity Lock）

来源：zenstory-drama-skills `short-drama-assets/references/continuity-lock.md`。

## 为什么识别锚点还不够

锚点是写给创作者读的事实；执行端只读得到每条提示词自己的正文。同一件毛衣第一镜
蓝色、第二镜红色，通常不是资产写错了，而是**没有任何一条提示词把颜色带进去**：
视觉设定写了，关键帧写了一半，视频提示词以为参考帧已交代就把重复描述删掉了。
参考图也补不上：角色板只约束它画到的部分，正在编织、被手挡住的道具、每镜重构图的
服装细节，都落在参考图"默认不能控制"的一侧。

## 什么值得上锁（三条同时成立）

1. 该可见事实出现于 ≥2 个镜头，或 1 个镜头 + 1 张资产板
2. 观众能直接看出前后不一致
3. 不随剧情改变——**会变的是状态，状态不上锁**

典型：服装主色与形制、道具主色与材质、发型长度、伤口位置与形状、招牌形制配色。
不上锁：情绪、姿势、左右手、镜头角度、时段光线、破损进度、持有人（归状态/分镜）。

## 锁面写法

锁面 = **要被逐字带进提示词正文的那一小段字**，不是描述，不是给人读的说明：

- 最小可辨识名词短语：`颜色 + 材质/形制 + 物体`
  例：`pale blue chunky knit wool sweater`
- 不含句号、动作、状态、数量、镜头信息、剧情
- 不写会随镜头变化的词（`in her hands` / `half-finished` / `on the sofa`）
- 一个实体一把锁；同一实体两种造型 = 两把锁，各写各的生效范围
- **一集 ≤5 把**：全锁上会把提示词撑满，挤掉本镜真正要执行的动作

## 语法规则

- 提示词可以在锁面前后加语法（`she keeps knitting the pale blue chunky knit wool sweater`）
- 但**不能改写锁面内部**——少一个 `stand-collar`、多一个逗号都算漂移
- 比较忽略大小写、换行按空格，其余逐字（card_check.py 就是这么查的）

## 反例

```
❌ "她的蓝色毛衣"        → 描述，不是锁面；无法逐字贴
❌ "blue sweater (EP03 起)" → 带状态与集数信息
❌ "elegant blue sweater"  → 空泛质量词，不可比较
✓ "navy blue wool cardigan with brass buttons"
```
