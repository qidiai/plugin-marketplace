# 角色看卡（drama-character-card）

**核心思想**：角色卡是角色视觉事实的**唯一真源**。分镜/出图阶段不再自己发明长相，
只引用卡里的锁面与锚点；一致性不靠模型自觉，靠卡 + 脚本校验。

**四家来源**：卡片结构与质量门 ← shuohao-skills；身份/变体三分法与连续性锁 ← zenstory；
6 段 identity block 与视觉指纹铁律 ← OnlyShot；提示词必带核心外貌 ← ai-manga-drama。

---

## 总工作流（6 步，Step 5 是硬门）

```
Step 0 摄入 → Step 1 拆角色表 → Step 2 逐角色出卡 → Step 3 提取连续性锁
     → Step 4 出 ref 设定图 → Step 5 质量门(⛔card_check.py) → Step 6 交付汇报
```

成本闸门（抄 OnlyShot）：文字层（Step 0–3）随便迭代；一旦进 Step 4 花图钱，
每张图用户确认后才继续。**先卡后图，先图后片**——设定图是分镜图的上游，
卡不纯则后面全救不回来。

## 项目目录约定

用户指定就用指定的；否则在当前工作区建 `character-cards/`：

```
character-cards/
├── cards/            # 每角色一份 card-<slug>.json（断点续跑单位）
├── images/           # <slug>-sheet.png
├── cast.json         # assemble 汇总（Step 6）
└── 角色卡.md         # 人读版汇总
```

## Step 0 — 摄入源判定（三选一）

| 源 | 做法 |
|---|---|
| **A 原著文本**（小说/网文） | 长文先分块（每块 ≤4 万字符）；每块扫一遍抽角色+引文；按"名字+别名"归并同人（同姓父子/兄弟**不能**仅凭包含关系合并，需逐条复核）；正文落 .txt 才能做引文逐字校验 |
| **B 剧本**（已有分集剧本） | 逐场提取出场人物与**可见**描述（服装/发型/持物）；区分"身份"与"变体"：换装/伤势/湿污是变体不是新人 |
| **C 口头描述**（用户直接说设定） | 缺什么**只问一轮**，把所有缺失项列全等回复：性别年龄、发型发色、瞳色、体型、标志性服饰、声线、核心反差点 |

## Step 1 — 拆角色表

- 分档：`protagonist`（主角）/ `major`（重要配角）/ `supporting` / `minor`
- **核心角色 ≤6 人**（成本 + 观众记不住）；超了给用户菜单砍
- 每人记录：名字、别名、画面代称（提示词正文里用什么指代它，见下）、分档、一句话定位

**画面代称**（抄 zenstory）：图片提示词**永远不写中文人名**（生成引擎吃英文最稳），
提示词正文用角色码指代（`CH-01`）。同一个角色全集只用一个拼写。

## Step 2 — 逐角色出卡

照 `templates/card-template.md` 写 `cards/card-<slug>.json`。要点：

- **识别锚点**：可见、可生成、可比较的具体事实（"左眼角小痣"），**不是**空泛质量词（"气质优雅"❌）
- **同批角色互相错开**：长相、发色、声线不得撞车——出卡时把同批其他角色的名字和锚点带上做查重
- 卡的分区（七层）：

| 层 | 字段 | 语言 |
|---|---|---|
| 身份 | id / name / aliases / tier / one_liner | 中文 |
| 看卡 | anchors[]（识别锚点） | 中文 |
| 锁 | locks[].face（连续性锁面） | **英文** |
| 图 | identity_block / image_prompt（ref 提示词） | **英文** |
| 变体 | variants[]（服装/状态按阶段） | 中文 |
| 声音 | voice.timbre_prompt / catchphrases | 提示词英文、台词中文 |
| 表演 | persona.contrast / five_closeups[] / signature_moves[] | 中文 |

## Step 3 — 提取连续性锁

**三条同时成立才上锁**（否则只留锚点）：
1. 该可见事实跨 ≥2 个镜头（或 1 镜头 + 1 资产板）
2. 观众能直接看出前后不一致
3. 不随剧情改变——**会变的是状态，状态不上锁**

**锁面写法**（抄 zenstory）：
- 锁面 = 会被**逐字**贴进每条相关提示词正文的那串字，不是描述
- 最小名词短语：`颜色 + 材质/形制 + 物体`，如 `pale blue chunky knit wool sweater`
- 不含句号/动作/状态/数量/镜头词；一实体一锁，两种造型两把锁
- **一集 ≤5 把**——每条锚点都上锁会把提示词撑满，挤掉本镜动作

## Step 4 — 出 ref 设定图（花钱闸门，先确认再批量）

**先读 `references/identity-block.md`（6 段模板 + 视觉指纹铁律）再写提示词**，铁律：
- ref 图 ≠ 成片：**neutral flat lighting**，绝不写 dramatic/cinematic/lens flare
- 视觉指纹放 prompt 开头前 200 token（权重最高），不是末尾
- NOT 词 ≤5（≥6 个生成效率掉到 30%）
- 一个角色一次调用，**绝不批量**；单失败跳过不阻断；图已存在就跳过（断点续跑）

**版面**（读 `references/sheet-layout.md`）：默认 16:9 三区 sheet
（左 34% 半身像基准 + 右上三视图 + 右下细节条）。两条硬要求：
三视图的脸必须与半身像一致；全身像比例不得为塞细节压扁。

本机出图用 `image_gen` 工具（或用户指定的即梦/dreamina 等外部管线，此时只交提示词包）。
出完给用户过目：脸型/服装/氛围不对 → 改 prompt 重跑（单图重跑很便宜），确认后才算完成。

## Step 5 — 质量门 ⛔ 不能跳

```bash
python <skill目录>/scripts/card_check.py character-cards
```

硬校验（任一 error 即 exit 1，逐条修复重跑直到通过）：
1. 结构完整（七层必需字段齐全、tier 枚举合法）
2. **锁面逐字**出现在该卡 image_prompt（大小写不敏感）
3. image_prompt / identity_block / voice.timbre_prompt **不含 CJK 字符**（语言分工铁律）
4. image_prompt 不含该角色中文名与别名
5. NOT 词 ≤5；image_prompt ≤1500 字符
6. 锚点不含空泛质量词（警告级）

## Step 6 — 交付与汇报

- 汇总 `cast.json`（角色数组）+ 人读版 `角色卡.md`（角色总览表 + 每卡详情）
- 一句话说清：角色数、出图数、报告路径；有失败/跳过/截断必须明说
- 下游衔接：分镜 skill 拿 `locks[].face` 逐字贴提示词，拿 `images/<slug>-sheet.png` 当参考图

---

## 边界

- 不生成分镜、不写剧本、不合并视频——只做角色看卡这一层
- 引文必须逐字（源为原著时）；含混指代不猜，标"未决"交回用户
- 单次处理上限 24 块文本，超了明说 `truncated`
- 改卡 = 改事实：任何视觉决定先改卡再生成，禁止只改提示词不改卡
