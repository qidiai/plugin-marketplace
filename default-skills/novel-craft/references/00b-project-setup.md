# 资料拆分(第三层:生成独立资料文件)

> 访谈完成后、动笔前必做。目的:把访谈答案拆成独立资料文件,作为**唯一真相源**——写作时从资料库查,不重复脑补。资料不齐不写正文。

## 流程按篇幅缩放(短篇简化,长篇全套)

| 篇幅 | 资料拆分 | 章节结构 | 修订 | 说明 |
|---|---|---|---|---|
| 短篇(1-10章) | 精简:风格+大纲+角色简表 | 可省(直接写) | 简化(修订+校对) | 一篇一个情绪弧,不建全套记忆 |
| 中篇(10-50章) | 标准:全套资料 | 每章结构 | 标准五层 | 记忆系统可精简(canon/issues必建) |
| 长篇(50+章) | 全套+细纲 | 每章结构必写 | 完整五层+Beta | 记忆系统全套,canon/issues必建 |

- 铁律:资料是唯一真相源——短篇可精简文档,但**不能省"设定一致性"**;长篇必须全套(连续性靠记忆系统)

## 资料生成顺序

```
风格指南(先定腔调) → 世界观(定规则) → 角色卡(定人物) → 势力卡/道具卡 → 大纲(定结构) → 章节结构(定单章分镜) → 记忆系统(定连续性)
```

## 章节结构文档(写草稿前的单章分镜)

> 每章动笔前必写 `设定/章节结构/第XXX章_结构.md`——**结构定了才写草稿,草稿写完才定稿移正文**。章节结构是"这章怎么拍"的导演分镜,草稿是"拍出来的成片"。

### 结构文档必含(9 项)

1. **本章大纲**:本章剧情骨架——按发生顺序分点列出(每点:谁+做什么+结果),即"这章要讲完什么"。与场景序列的区别:大纲管"剧情走向",场景序列管"镜头怎么切"
2. **本章定位**:剧情功能(推进/转折/蓄力/收束)+ 情绪曲线(起→伏→收)
3. **场景序列**:本场景列表(每场:地点/时间/视角/在场人物/发生什么/转场动作)
4. **视角安排**:本章视角人物(谁是谁)+ 切换断点(独立成段处)+ 每段不混人称
5. **节奏设计**:七段式分布(铺垫→冲突→爆发→缓收),哪段短句密集/哪段长句绵长
6. **章末钩子**:4型之一(悬念/反转/情绪炸弹/信息投放),具体落笔处
7. **伏笔落点**:本章埋了什么伏笔(记入伏笔台账)/回收了什么伏笔(勾销台账)
8. **描写维度选维**:本章场景按 02b 选维(风景12维/建筑/事物/食物/动物/人物八维/生活),每场选 2-4 维
9. **跨章衔接**:上章末人物状态(衣着/伤势/位置/神志/道具)→ 本章初状态严丝合缝

## 草稿 → 正文 流转规则(三阶段:结构→草稿→正文)

0. **先定结构**:写草稿前必先产出 `设定/章节结构/第XXX章_结构.md`(9项:大纲/定位/场景/视角/节奏/钩子/伏笔/描写维度/衔接)——**结构未定不写草稿**
1. **先写草稿**:每章初稿落在 `草稿/`,写作循环(写中规格)在草稿上执行,按章节结构文档落笔
2. **草稿=正常文章,非片段**(2026-08-04新增硬约束):
   - 草稿必须是**完整连贯的正常文章格式**——自然段落、通顺成文,与最终正文同规格
   - **禁写片段**:不允许只写场景提纲/对话零碎/关键词堆砌;禁"此处待补""[TODO]""省略部分"类占位符
   - **禁段落线**:不允许用 `---`/`***`/分隔符/编号标记切分未完成段落(那是草稿提纲或写作备忘,不是文章);正常文章只允许空行分段
   - **字数达标**:草稿即满足本章字数目标(网文3000-5000,纯文学≥3500),未达标视为未写完
   - 段落线/备注/占位符只允许出现在 `## 构师备注` 元数据段,正文区一律成文
3. **定稿才移入**:草稿通过完稿检查(07清单+check-chapter.py)后,`git mv`/移动至 `正文/`
4. **正文=已发布**:`正文/` 内章节视为定稿,改它需走"修订流程"(登记原因,非随手改)
5. **归档**:废弃/旧版稿移 `归档/`,不留在草稿或正文
6. **记忆同步**:章节从草稿移入正文时,同步回写记忆系统(摘要/弧线/时间线/伏笔/爽点)

## 写前必读(2026-08-05新增硬约束:防丢背景/防断连贯)

写任何一章(尤其新章)前,按此清单读齐,再动笔:

1. **记忆系统五件套**:故事圣经(全书速查)/人物弧线(各角色当前状态)/时间线(日期/年龄/事件顺序)/伏笔台账(该回收的回收了吗)/爽点台账(该给的回报给了吗)
2. **本章结构文档**:`设定/章节结构/第X章_结构.md`——按它落笔,不临场发明
3. **已完成章节正文(关键)**:重读**上一章正文**(含 `## 构师备注`)+ **全书已定稿正文的关键段**——尤其:
   - 上一章末人物状态(衣着/伤势/位置/神志/手持道具)→ 本章初必须严丝合缝
   - 上一章末场景/氛围/情绪落点 → 本章开头衔接
   - 涉及伏笔/意象/道具的既有描写原文(布条/玉/小袄/勒痕等)——防止写岔/写丢
   - 构师备注里的"连贯性核对/衔接"段——作者已确认的跨章契约
4. **风格指南**:文风/禁词/人物腔调
5. **本章大纲**(大纲.md 对应行)+ 前章衔接说明
6. **避坑清单**(references/13-pitfalls.md):涉群像/性场景/胁迫/多角色时,先过一遍坑1-6/9-12——防止旧坑复发

> 原则:宁可多读一遍已完成章节,不可凭记忆写新章——背景与连贯性以正文实际文字为准,不靠回忆。

## 二、各资料要点

### 风格指南.md(先写)
- 文风基调 / 句长偏好 / 叙事腔调 / 比喻策略 / 方言口语度
- 禁词清单(此书的专属禁词)
- 范文片段(有则贴,用于风格校准)

### 世界观.md
- 力量体系(修炼/魔法/科技:境界/等级/规则)
- 地理/势力分布
- **社会分层(阶级梯子)**:世界的阶级有几层/依据什么/各层权力穿着财产生活行为边界(见 02-character 二点五节 第0步)——地位是世界观规则,不是人物卡字段
- 核心规则(什么能做/不能做)
- **设定一致性**:力量体系必须自洽,写前先定规则再写情节

### 角色卡(每主要角色一份)
按 `templates/character-card.md`:
- 基础档案(姓名/年龄/身份/修为)
- **社会地位(阶级坐标)**:出身地位×修为地位双线+地位五要素(权力/穿着/财产/生活/行为边界)——见 02-character 二点五节(所有类型通用)
- 性格分层(表层/中层/底层)
- 关系网
- 身体与情欲(若成人向)
- 人物弧线
- 写作禁区(不可写成什么)

### 大纲.md
- 卷结构(每卷主题/冲突/情绪曲线)
- 章规划(每章:视角/场景/情绪/章末钩子)
- **黄金三章**(前3章:抓读者/立主角/埋钩子)
- 伏笔规划(埋设章/回收章)

### 记忆系统(长篇连续性核心)
每章写完回写:
- 故事圣经:核心设定速查(不随剧情漂移)
- 人物弧线:每角色当前状态(情绪/修为/目标)
- 时间线:故事内日期/年龄/事件顺序
- 伏笔台账:埋设了哪些/该回收哪些
- 爽点台账(网文):埋了哪些期待/该给哪些回报

## 三、铁律

1. **唯一真相源**:资料库是设定唯一出处,正文/访谈/记忆都向它对齐
2. **不重复脑补**:写作时先查资料,不现场发明设定
3. **设定变更走登记**:要改设定,先改资料库,再改正文;改完在记忆系统登记
4. **前史必落正文**:角色来历/家世/秘密,必须在正文有记忆点,不"后面才补"
5. **角色修为/力量必交代**:玄幻世界,人物有修为必写清楚(境界/功法/斗技)
