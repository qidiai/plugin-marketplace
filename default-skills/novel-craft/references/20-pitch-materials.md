# 投稿与发布材料(20)——书名/简介/封面/标签

> 处理"发布材料怎么写"的规格。**何时读**:作品要发布前——书名、简介、封面文案、标签选择决定点击率。
> 定位:内容写好了,但读者是先看到"书名+简介+封面"才决定点不点——这些是作品的"门面"。

## 一、书名(3-10字,一眼懂题材)

- **带关键词**:重生/穿越/系统/古言/甜宠/末世…——让读者扫榜单时一眼定位
- **带钩子**:冲突/反差/悬念("从赘婿到战神""病弱太子妃")
- **忌**:晦涩/装X/看不出题材/太长
- **自查**:扫一眼榜单,我的书名能让人知道"这是什么题材"吗?

## 二、简介(前两行定生死)

- **前两行**:冲突+期待+差异化——决定点击率
- 结构(常见):
  - 主角+处境(反差/困境)
  - 目标/金手指(他要做什么/凭什么)
  - 悬念/钩子(读者为什么想知道后面)
- **忌**:剧透结局/流水账剧情简介/无冲突描写
- **自查**:读完前两行,我想点进去吗?

## 三、封面与标签(影响推荐量)

- **封面**:符合平台尺寸/题材风格(玄幻要酷/古言要雅/甜宠要暖)
- **标签**:选对标签=进对推荐池(平台按标签分发流量)
- **自查**:我的标签能进目标读者的推荐池吗?

## 四、投稿材料(传统出版/实体)

- **query letter(询问信)**:一段话介绍作品(题材+钩子+为什么有人读),用于投出版社/编辑
- **synopsis(故事梗概)**:1-2页,全剧透式概述(结局也要写)——编辑看结构是否成立
- **样章**:前1-3章(最好的章节)
- **作者简介**:简短,显示你能持续产出

## 五、完稿自查(发布前)

- [ ] 书名带关键词+一眼懂题材吗?
- [ ] 简介前两行有冲突+期待吗?
- [ ] 简介没剧透结局吗?
- [ ] 封面符合平台规格/题材风格吗?
- [ ] 标签选对了吗?(能进目标推荐池)
- [ ] 实体投稿:query letter/synopsis/样章齐了吗?

## 六、与其他规格的关系

- 平台规则 → 17-platform
- 市场定位 → 15-market-research(书名/简介=差异化落地)
- 黄金三章 → 16-golden-three(样章=前三章)
