# 文笔表达规格(23)——7维度逐层审校

> 处理"文字质量本身"的规格。**何时读**:每章写完后必读——在 07-checklists 和 13-pitfalls 之后,作为第三层检查。修订时(14-revision)的行级修订(第3层)和文字编辑(第4层)也查此规格。
> 定位:04-anti-ai 管"AI味"(禁词/禁结构),07-checklists 管"检查清单"(逐条勾),13-pitfalls 管"实战避坑"(踩过的坑)——本规格管"文字质量"(从语句到人物的7个维度)。四者互补,不重复。

## 七维度速查表

| 维度 | 管什么 | 核心铁律 |
|---|---|---|
| 1 语句通顺 | 病句/成分残缺/语序混乱/主语跳变 | 主谓宾完整、搭配要"对"、主语承接清晰 |
| 2 优美表达+逻辑顺畅 | 文采/节奏/句间逻辑 | 动词精准(不可替换的词)、长短句交错、逻辑承接不跳 |
| 3 段落逻辑手法 | 段内结构/段间过渡 | 一段一意、段段有功能、用动作/时间/环境过渡 |
| 4 全章连贯+风格统一 | 场景衔接/时间线/风格 | 场景=时间顺序、风格全章一致、情绪有起伏 |
| 5 留白与充实 | 详略控制 | 关键场景写透、过渡留白、情感高点前半句收住更狠 |
| 6 虚实表达 | 情绪外化/心理实写 | 虚落实(身体反应/动作/物件)、实带虚(动作后暗流)、禁情绪标签 |
| 7 人物品性立体 | 奸狡/忠厚不标签 | 善恶通过行为显形、奸狡有他的"理"、忠厚有他的私心、关键时刻显品性 |

## 各维度详解与自查

### 维度1·语句通顺

**症状**:病句、成分残缺(缺主语/缺宾语)、语序混乱、主语跳变(同段主语从A跳到B再跳回A)

**铁律**:
- 主谓宾完整——每句能找到主语和谓语,宾语不缺
- 搭配要"对"——动宾搭配不别扭("打碎镜子"对,"打碎声音"错)
- 主语承接清晰——同一段内主语变换时必须有标记("他走了。她站起来。"不能写成"走了。站起来。"除非语境极清晰)

**自查**:逐句读,找主语。主语在哪?谓语是什么?搭配别扭吗?

### 维度2·优美表达+逻辑顺畅

**症状**:文采不足(全是平铺直叙)、节奏单调(句长一致)、句间逻辑断裂(上句说A下句跳到C)

**铁律**:
- 动词精准——用不可替换的词。"走"不如"踱","踱"不如"拖着脚走"。每个动词问:有没有更准的?
- 长短句交错——紧张/动作用短句(≤15字),氛围/内心用长句。全段同长=催眠
- 逻辑承接不跳——上句到下句之间有隐含的逻辑链。读者不需要你解释,但需要能"接上"

**自查**:每句的动词能不能换更准的?句长有没有变化?上句到下句读起来"跳"吗?

### 维度3·段落逻辑手法

**症状**:段内杂乱(一段写三件事)、段间生硬(硬切无过渡)、段落无功能(删掉不影响)

**铁律**:
- 一段一意——一段只写一件事/一个情绪/一个场景
- 段段有功能——每段在全文中有存在理由(推进/铺垫/转折/喘息)。删掉如果没影响=该删
- 过渡用动作/时间/环境——不用"过了一会儿""与此同时"。用"他放下碗"过渡,用"窗外暗了"过渡

**自查**:这段写了几件事?超过一件就拆。这段删了有影响吗?没影响就删。

### 维度4·全章连贯+风格统一

**症状**:场景乱跳(时间线错乱)、风格漂移(前半冷峻后半煽情)、情绪平线(从头到尾一个调)

**铁律**:
- 场景按时间顺序——除非有意倒叙,否则场景排列=时间排列
- 风格全章一致——冷峻的文风不突然变煽情。如果要有变化,是渐变不是跳变
- 情绪有起伏——不能从头平到尾。有铺垫有爆发有缓收(参考七段式节奏 03-pacing)

**自查**:场景顺序和时间线一致吗?文风前后一致吗?情绪曲线有起伏吗?

### 维度5·留白与充实

**症状**:该写透的没写透(关键场景一笔带过)、不该写的写太多(过渡段啰嗦)、情感高点没收住

**铁律**:
- 关键场景写透——打斗/对峙/情感爆发/真相揭露,要写足细节和层次
- 过渡留白——日常/赶路/等待用一两句带过,不铺陈
- 情感高点前半句收住——"他想说对不起,但——"比"他想说对不起,但最终没有说出口,因为……"更狠。高点处留白比写满更有力

**自查**:这章的关键场景写透了吗?过渡段是不是太长了?情感高点处收住了吗?

### 维度6·虚实表达

**症状**:情绪标签("她感到恐惧")、心理直白("他心里想着")、纯虚不落实(全是形容词没有画面)

**铁律**:
- 虚落实——情绪/心理用身体反应/动作/物件表达。"恐惧"→"手指掐进砖缝,指甲断了半根也没觉得疼"
- 实带虚——动作之后可以有暗流,但暗流是暗示不是标签。"他放下碗。碗在桌上转了半圈。"——不说他什么心情,碗转了半圈就是暗流
- 禁情绪标签——禁"她感到/他觉得/他心中/她意识到"。用身体和动作替代

**自查**:这段有情绪标签吗?有"她感到/他觉得"吗?情绪用身体表达了吗?

**与04-anti-ai的关系**:04的AI-3(禁情绪标签)和AI-11(禁模糊缓冲词)是本维度6的具体执行。04给禁词清单,本维度给"虚实转换原理"——为什么禁、用什么替。

### 维度7·人物品性立体

**症状**:人物标签化(奸人就从头奸到尾)、善人无私心、恶人无道理、关键时刻品性不出

**铁律**:
- 善恶通过行为显形——不写"他是个好人",写他做了什么好事。不写"他阴险",写他怎么算计
- 奸狡有他的"理"——反派不觉得自己是反派。他有他的逻辑、他的立场、他的苦衷
- 忠厚有他的私心——好人也有私心。无私心=纸片人
- 关键时刻显品性——平时看不出人品,生死关头/利益面前才显。关键时刻的选择=人物的核心

**自查**:这个人物是标签化的吗?他有"理"吗?他有私心吗?关键时刻他的选择符合品性吗?

**与02-character的关系**:02管"怎么写人"(写人四法/七维度/活人化),本维度7是02的品性层提炼——02给方法,本维度给检查标准。

## 审校流程(写后三层检查)

```
写完一章 →
第1层:07-checklists(逐条勾:禁词/视角/人物/逻辑/节奏/风格) →
第2层:13-pitfalls(避坑:群像/视角跳切/威胁缺位/对话禁词等) →
第3层:23-prose-expression(本规格:7维度逐层审校) →
不达标即修。修完重走一遍。
```

三层检查的分工:
- 07:对不对(合规性)——禁词有没有?视角对不对?逻辑通不通?
- 13:踩没踩坑(实战性)——群像有没有给人戏份?威胁有没有升级?跨章状态对不对?
- 23:好不好(质量性)——动词精不精准?留白够不够?虚实转换对不对?人物立不立得住?
