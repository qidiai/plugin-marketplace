# 视角铁律(每章必读)

> 写谁就是谁的视角。人称/称呼/词汇全部跟随当前视角人物,全书不搞机械人称统一。切换视角=切换整个世界。

## 核心原则

**写谁就是谁的视角**:当前写谁,就进入谁的"我"/称呼/词汇。
- 例:写女儿视角→"爹娘大哥妹妹";写当家主母视角→"夫君/妾身/孩子们";写反派视角→他用他那一套词(把目标当"货/猎物")

## 执行细则

### 1. 视角总则
- 每章/每场先定"谁在看",人称跟着这个人走
- 叙述者所知=视角人物所知,不跨头
- 视角人物亲属直呼:爹/娘/大哥/妹妹,禁"她爹/她娘"
- 其他人物(非视角)在叙述中用"他/她/娘/爹"

### 2. 限知镜头
- 他看到的读者看到,他看不懂的读者也看不懂(留给后续视角揭)
- 禁上帝视角:"她不知道的是/殊不知"——读者需要知道而视角人物不知道的真相,用草蛇灰线暗示,叙述者不跳出来解说

### 3. 镜头与直白词分离
- 镜头是角色的(看见的画面/反应)
- 器官词是叙述者的(器官/体液直白词不要求角色认知里有)
- 视角角色不推断(她只看见某人的手碰酒杯,不下"在下药"的结论)

### 4. 内心进行时
- 内心/身体体验用"我"+进行时碎片("完了。谁在碰我?别……")
- 禁回溯总结("她意识到被侵犯,感到屈辱"——这是作者总结)

### 5. 转述词禁令
- 禁"她想/她觉得/她心里/她忽然明白/她不知道/她以为"等转述词——内心独白直接以"我/直接动词"呈现

### 6. 避免"我我我"流水账
- 感官/动作/客观开头:"窗户嘎嘎作响"比"我听到窗户嘎嘎作响"好
- 省略主语:"站起来。"比"她站起来"好
- 变换句式,动词精准化

## 双视角(像看电视一样)

- 主角镜头(她看到的)+ 上帝/第三人称镜头(她看不到的,如正屋夫妻戏)
- 切换断点清晰:独立成段,不混写
- 上帝镜头只用于"观众需要看到的、主角看不到的"关键画面,不滥用

## 多视角场景·三重分工(2026-08-04实战定稿)

用于强暴/群戏/对峙等多人同场的大场景。

- **主角内心 = 第一人称"我"**:被压制/被侵入的身体感受+受害者的内心层次(羞耻/生理反应/恨意/清醒谋划)全用"我"
- **对立方视角 = 第三人称+身份锚**:按外貌或职分特征称呼(如"缺牙的/领头的/掌印的"),写其冷、职业逻辑(查验/验收/检查)、满足;零洗白,不抒情,不"被欲望打动"
- **旁观者插叙 = 第三人称+锚点**:("她趴在门缝边…她看见母亲…",称"娘/爹/大哥"等视角人物的亲属称呼)——镜头的跳切,不是主角
- **一章只允许一个"我"**:同章内第一人称"我"=唯一的视角主人物;其余角色一律第三人称+锚,绝不让第二个角色也用"我"插叙(两个"我"相邻=读者灾难)
- **断点铁律**:三者切换均独立成段,同段内不混人称
- **主角"我"可在段落间退场**:主角昏迷/意识模糊时改由旁观者/对立方视角呈现;主角清醒行动/算计时可回旁观镜头+叙述者直写,不必强切"我"(留白让读者拼的戏尤其如此)

## 常见错误

| 错误 | 表现 | 修正 |
|---|---|---|
| 视角穿越 | 同一段写主角心理又写反派得意 | 切在章节断点,一场戏一个主镜头 |
| 叙述者替角色知道 | "娘早知道他藏了东西" | 加推断锚"她想,他大概是知道些什么的" |
| 转述词 | "她意识到/她感到" | 改身体反应或内心进行时碎片 |
| 超认知词/推理 | 少女说"鸡巴"/少女下"在下药"的结论 | 镜头是她看的,器官词是叙述者的 |
| 视角位置错乱 | 人在院子却写"在密室里" | 空间移动每步交代 |
