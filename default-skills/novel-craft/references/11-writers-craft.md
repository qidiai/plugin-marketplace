## 阅读路径建议

- **写长章/试概要、画面不足** → 先看海明威 / 契诃夫 / 余华(白描、细节承载情绪)
- **写前要憋氛围、留白** → 海明威、加缪、卡夫卡、古龙
- **写人物"活不起来"** → 契诃夫、老舍、汪曾祺、纳博科夫(怪癖即性格)
- **写节奏/爽点/追读** → 猫腻、天蚕土豆、爱潜水的乌贼、网文流派表
- **写大场面 / 多人物交叉** → 托尔斯泰、马尔克斯、烽火戏诸侯
- **开头难 / 起手抓人** → 马尔克斯、陀思妥耶夫斯基、菲茨杰拉德
