# 完稿检查清单(每章写完逐条核)

> 每章完稿必读,逐条勾选。不达标不交付。涉及时才查的项(性场景/世界观/爽点)标注"仅当涉及"。

## 一、文字

- [ ] 禁词0:"操/然后/接着/于是/说不清/莫名"(成人向作品用"肏"替"操")
- [ ] 转述词0:"她想/她觉得/她感到/她意识到"
- [ ] 上帝视角0:"她不知道的是/殊不知"
- [ ] 作者抒情0:"青砖上是她家的地/说不清为什么"
- [ ] 心理滤镜0:"这意味着/原来如此/这说明"
- [ ] 病句0:成分残缺/搭配不当/重复("油纸包,油纸包是温的")
- [ ] 字数≥本章目标(网文3000-5000,纯文学≥3500)

## 二、视角

- [ ] 写谁就是谁的视角(人称/称呼/词汇跟随)?
- [ ] 限知镜头不跨头?
- [ ] 镜头与直白词分离,视角角色不推断?
- [ ] 双视角切换断点清晰(独立成段)?
- [ ] 视角位置每步交代,无提前跳场景?

## 三、人物

- [ ] 主要人物"被看见"而非被介绍?
- [ ] 每角色≥3层细节,标志细节≥3次换角度?
- [ ] 群像人人反应不同?
- [ ] 配角核心瞬间(旧习惯写碎裂)?
- [ ] 重要配角铺垫锚(习惯动作贯穿后文)?
- [ ] 战斗人物有血肉感(青筋/厚茧/汗水)?
- [ ] 体面崩塌有过程(先护体面再崩)?
- [ ] 修为/功法/境界有交代且符合世界观?
- [ ] 人物OOC检查(与角色卡/弧线一致)?

## 四、描写维度(涉及场景/物件/饮食/动物/生活段落时)

- [ ] 风景:≥2种感官(视觉外有听觉/嗅觉/触觉之一)?有远中近层次或视线顺序?有光影/动态/线条之一?景服务了当下人物情绪或剧情功能?**从世界组成维度选了2-4维**(地形/地貌/水文/天象/气象/气候/季候/植被/生灵/地质/人文痕迹/题材专属)?**题材专属:景里有一笔"只有这个世界才长得出"的维度**(玄幻=灵气/魔兽,科幻=科技/异星,现代=城市/网络,古典=礼教/世家,末日=废墟/变异……不限玄幻)?**季节现象无歧义**(季节性的白/枯/雾/冻说清是雪/霜/雾/枯黄/封冻,不靠读者猜)?
- [ ] 事物:物件承担了剧情功能(结点/铰连:传递/易手/毁损即剧情)?有质感(重量/温度/触感)?来历交代?具象先于象征?
- [ ] 食物:≥3感在场(色香昧触声)?有"记忆点动作"(扎/掰/咬/撕的瞬间)?家常烟火气而非摆盘堆砌?吃相写了性格?
- [ ] 动物:外形从整体到最有特征部位?习性即性格(禁标签)?有物种专属动作细节?拟人有物种边界?
- [ ] 人物八维:出场只选2-4维写透(禁八维全写=人物卡)?各维有核心一问落点(传神部位/体积/动作中显/架式/衣饰即处境/戴摘皆戏/表情过程/习惯动作)?
- [ ] 生活:吃喝拉撒睡五维具象(空间/关系/经济/身体/时间)且不强行升华?性交/偷窥/意淫段落按 02b 六+05b/05 规格?
- [ ] 房屋建筑:建筑暴露了主人的阶层/处境/性格(形制/材质/新旧)?有空间格局与动线(人在其中走动,非户型图罗列)?从7维选了2-4维写透(结构/空间/采光/陈设/痕迹/声气/风水)?建筑承担了剧情功能(空间即权力/门是戏眼/兴衰即家族)?玄幻/异世界有"只有这世界才长得出"的建筑元素(阵法/禁制/灵材/宗门之势)?
- [ ] 类型腔调:文风符合本书主类型(仙侠飘逸/古典蕴藉/修真硬核/武侠侠气/耽美情纲/架空自洽/穿越落差)?
- [ ] 修炼体系自洽:境界/功法/丹药/法宝的品阶与能力边界前后一致(同级战力可比、越级必有手段或代价,参考 06-worldbuilding 对齐规则)?升级有卡点/代价(瓶颈/心魔/资源缺口)而非水到渠成?境界名词全书统一,禁前期设定后期打脸?

## 五、性场景(仅当涉及)

- [ ] 必写清单逐条对(潮红/僵瘫/蜷缩/不应期/喷当尿/口交/失禁/说不出话)?
- [ ] 觉醒链三阶,算计不在肏喷前?
- [ ] 非自愿:身体+心理并行,无美化?
- [ ] 脏了之后爽+恨并存?
- [ ] 轮奸每轮换焦点?
- [ ] 直白词用对(禁替代词)?

## 五、逻辑/场景

- [ ] 场景切换有动作交代,时间线连续?
- [ ] 人物出场状态链条完整(躲→被抓→在桌上)?
- [ ] 空间装置物理闭环(隔音/透声)?
- [ ] 暴力/灭门之因符合世界观(不硬找合理借口)?
- [ ] 伏笔"读者第一遍是日常,事后回看才恍然"?
- [ ] **跨章人物状态一致**(2026-08-04实战教训):人物跨章承接时的身体状态必须与上一章末尾严丝合缝——上一章末已脱光/受伤/昏迷,下一章开头就不能穿戴整齐/完好无损/清醒。逐项对:衣着(赤身/穿戴/破损)、伤势(淤青/牙印/掌印/血)、位置(跪/躺/被架/站)、手持道具(杯碗/武器/药)、神志(清醒/昏迷/恍惚)。跨章第一句要对得上上一章最后一句
- [ ] **章内道具统一**(2026-08-04实战教训):同一场景同一类道具的形制要全场一致(如酒具全用碗或全用杯),不能前半场用碗、后半场又冒出一个杯。场景开写前先定道具清单(谁拿什么/什么材质/会不会坏/从哪来)

## 六、节奏

- [ ] 章末钩子是4型之一(悬念/反转/情绪炸弹/信息投放)?
- [ ] 危险时刻无内心戏?
- [ ] 环境是人的延伸?
- [ ] 重大事件后有空白页?
- [ ] 本章情绪有起伏(铺垫/爆发/缓收)?

## 七、风格

- [ ] 文风与 style-guide.md 一致?
- [ ] 对话符合各角色腔调(不千人一面)?
- [ ] 无风格漂移(突然变网文腔/突然变文言)?
- [ ] 感官/比喻/句长符合本书偏好?

## 八、记忆回写(写完必做)

- [ ] 章节摘要更新(本故事内发生了什么)?
- [ ] 人物弧线更新(各角色当前状态)?
- [ ] 时间线更新(日期/年龄/事件顺序)?
- [ ] 伏笔台账更新(埋了哪些/回收了哪些)?
- [ ] 爽点台账更新(网文:埋了哪些期待/给了哪些回报)?

## 九、文笔质量7维度(第三层检查,查 `references/23-prose-expression.md`)

- [ ] 维度1 语句通顺:主谓宾完整?搭配别扭?主语跳变?
- [ ] 维度2 优美表达:动词精准?句长有变化?句间逻辑不跳?
- [ ] 维度3 段落逻辑:一段一意?段段有功能?过渡用动作/环境?
- [ ] 维度4 全章连贯:场景按时间顺序?风格一致?情绪有起伏?
- [ ] 维度5 留白与充实:关键场景写透?过渡不啰嗦?高点收住了?
- [ ] 维度6 虚实表达:禁情绪标签?情绪用身体表达?虚落实?
- [ ] 维度7 人物品性:不标签化?善恶通过行为显形?关键时刻显品性?
