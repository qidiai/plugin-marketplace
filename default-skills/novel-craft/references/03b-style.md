# 写作风格技法(每章必读)

> 风格=词汇+句法+腔调的系统,不是形容词堆砌。每章写作前查项目的 style-guide.md,写作中按本规格执行。

## 一、风格是什么

风格不是"文笔好",是**稳定的、可复现的语言系统**:
- 词汇选择(用哪些词/不用哪些词)
- 句法节奏(短句/长句/交错)
- 叙事腔调(冷叙述/代入/间离)
- 感官偏好(偏视觉/嗅觉/触觉)
- 比喻策略(密集/克制/禁用)
- 口语度(书面/市井/文言夹白)

## 二、风格怎么落地(不是堆形容词)

**例**:古风骨架+市井血肉——前一句雅(如"月照廊下,霜色初凝"),后一句直(如"他扯开衣带,把她抵在墙上")。这种落差是文体特质:前一句雅,后一句直,落差本身就是力量。

- 同一风格下不同场景有变体:日常段/战斗段/亲密段的节奏切换(紧张短句/舒缓长句)
- 风格服务叙事,禁"为风格而风格"(华丽词藻盖过情节=空)

## 三、风格要素清单(查 style-guide.md 逐项)

1. **文风基调**:古风/现代/华丽/朴素/冷峻——通篇一致
2. **句长**:短句密集(动作/暴力/决断)/长句绵长(情绪/内心/氛围)/长短交错
3. **腔调**:冷叙述(不评判只呈现)/代入式(贴角色感受)/间离(拉开距离)
4. **感官偏好**:定主感官(视觉为主,关键时刻叠听觉/嗅觉/触觉)
5. **比喻**:克制使用(每千字≤1个),比喻必须从在场实物延伸,不是漂亮话装饰
6. **口语度**:人物对话带语气词/省略/打断,禁书面化
7. **禁词清单**:本书专属禁词(如禁"然后/接着/于是/说不清/莫名");成人向作品可加"禁'操'用'肏'"等专属规则

## 四、用范文蒸馏风格(有参考书时)

- 找3-5段目标文风的范文
- 提炼:句长基线/段落节奏/感官偏好/比喻指纹/禁忌清单
- 写入 style-guide.md,写作时对照

## 五、风格一致性(完稿复查)

- [ ] 本章文风与 style-guide.md 一致?
- [ ] 对话符合各角色腔调(不千人一面)?
- [ ] 无风格漂移(突然变网文腔/突然变文言)?
- [ ] 感官/比喻/句长符合本书偏好?
