# 描写维度技法(场景/实物/饮食/动物/人物八维/生活)

> 覆盖七类描写对象的维度拆解:风景(含自然景观的世界组成维度)、房屋建筑、事物/实物、食物、动物、人物(八维细分)、生活(吃喝拉撒睡/性交/偷窥/意淫)。
> 与 02-character.md 互补:02 管"人怎么活"(写人四法/活人化/一致性),本文件管"物怎么描"(六类对象的维度清单与具体技法)。人物八维是 02 七维度的描写层细化,写"被看见"的那一瞬对照本文件选维度。
> 涉及性交/非自愿时,须同时读 05-sensitive.md 与 05b-sex-scenes.md。

## 一、风景描写

### 0. 先选维度:自然景观的世界组成(写景第一步)

- 写景先问:这一片景,是"哪个世界"的景?世界的组成维度就是景的骨架。从下表选 2-4 维落笔(与人物八维同则:选少选透,禁全维平铺)
- 维度与技法分工:本表管"写什么"(选哪些世界组成要素),1-7 节管"怎么写"(五感/层次/光影/动态/线条/情绪)——先选维,再上技法

| 维度 | 核心一问 | 一句话技法 |
|---|---|---|
| 地形(山/原/谷/漠/川) | 这块地是起伏还是平坦? | 先定地势走向,再落具体一处 |
| 地貌(峡谷/丘陵/喀斯特/丹霞/冲积扇/沙丘/冰川/溶洞等具体形态) | 地表长成什么形状? | 地貌是地形的"脸":同一座山,峡谷与溶洞是两个世界 |
| 水文(江/湖/海/泉/瀑) | 水在动还是静? | 水是景的血脉,动则活,静则藏 |
| 天象(日月/星/云/雾/虹) | 天上挂着什么? | 先写光与云,再写被光照见的地 |
| 气象(风/雨/雪/霜/雷/晴) | 天气在变还是定? | 气象即情节的呼吸,变天即变局 |
| 气候(一地常态:四季规律/海拔温差/霜雪期/旱雨季) | 这个地方长年是什么天气? | 气候是"白了头"的答案——雪/霜/雾必须说得清,禁季节现象歧义 |
| 季候(春/夏/秋/冬/时辰) | 这是哪一季哪一刻? | 季节时辰是时间的实体,顺手完成时间交代 |
| 植被(林/草/花/藤/庄稼) | 地上长着什么? | 草木的疏密枯荣=地的富贫死活 |
| 生灵(兽/鸟/虫/鱼/家畜) | 谁在这里生活? | 一只活物顶十句静物 |
| 地质(土/石/矿/沙/尘) | 脚下踩着什么? | 土质决定这地方能长什么、能活什么人 |
| 人文痕迹(路/村/碑/废墟/界碑) | 人在自然里留下了什么? | 自然刻度上叠人的痕迹,景才有纵深 |
| 题材专属(此世界独有:玄幻=灵气/魔兽/宗门之势,科幻=科技/外太空/异星生态,现代=城市/网络/霓虹,古典=礼教/科举/世家,末日=废墟/变异/幸存者) | 这个世界独有的大地规则显形了吗? | 每个题材都有"只有这个世界才长得出"的一笔——禁通用模板景 |

- 用法:一段风景先定位"这景属于世界的哪一格"(山野/水域/荒漠/宗门灵脉/城郊?),再选 2-4 维,配 1-6 节技法去写
- 禁:把景写成任何世界都能套的通用模板(有灵气设定的世界,景里一丝灵气痕迹都没有=失职);全维平铺(十二维各写一句=说明书)

### 1. 五感全景(视觉不是唯一)

- 视觉为主,但至少带一感非视觉:听觉(风/水/虫鸣/檐铃)、嗅觉(土腥/草木/烟火/霉味)、触觉(风贴颈/石板凉/露水湿)、味觉(空气的潮/甜/涩)
- 规则:一段风景至少两种感官,禁"纯眼睛看"的平面罗列

### 2. 电影感层次(镜头推移)

- 由远及近:远景(天际线/山形/天光)→ 中景(屋宇/树/巷)→ 近景(门/窗/阶)→ 特写(一片叶/一只虫/一滴水)
- 镜头跟着人物视线走:人物先看见什么,再看见什么,就是他的注意力顺序,也是他的心理顺序
- 禁:一段内无顺序地堆叠名词("山、水、树、云、桥、舟"平铺)

### 3. 光影优先(先光后物)

- 先写光,再写被光照见的东西:"暮色压下来"→"瓦上的霜反着最后一点白"
- 光即情绪:晨光是"新",正午光是"裸",黄昏光是"迟",夜光是"藏"
- 光影变化=时间流逝的物理证据(日影/灯影/烛火动),顺手完成时间交代

### 4. 动态优先(静景找动)

- 纯静态景物=死景。找动:风动(旗/发/叶)、水动(波纹/倒影碎)、烟动(炊烟/香火/尘)、生物动(鸟/虫/人)
- 以声衬静:越静越要有一声(针落/烛花爆/远吠),静才有纵深

### 5. 线条与留白

- 写线条:屋脊的线/山的脊线/路的延伸线,线条即构图,也即"气"的走向
- 留白:不写满,景物的三分之一留给读者补。禁把一处景写尽写透(那是说明书)

### 6. 情绪滤镜(无情绪不写景)

- 景是人物心境的投影,同一片景,不同心境下笔墨完全不同
- 伤心人看景:物象冷、远、沉("雨是冷的,瓦是黑的,灯火是别人的")
- 得志人看景:物象亮、近、轻
- 禁:纯客观写景(与人物情绪无关的大段风景=抒情废段,先问"这段景为谁的情绪服务")

### 7. 检查要点

- [ ] 至少两种感官?视觉外有听觉/嗅觉/触觉任一?
- [ ] 有远中近层次或视线顺序?
- [ ] 有光影/动态/线条之一?
- [ ] 景服务了当下人物情绪或剧情功能?
- [ ] 从世界组成维度选了 2-4 维落笔(地形/地貌/水文/天象/气象/气候/季候/植被/生灵/地质/人文痕迹/题材专属)?
- [ ] **题材专属**:景里有一笔"只有这个世界才长得出"的维度(玄幻=灵气/魔兽,科幻=科技/异星,现代=城市/网络,古典=礼教/世家,末日=废墟/变异……不限玄幻)?
- [ ] **季节现象无歧义**:季节性的"白/枯/雾/冻"等描写说清了是什么(雪/霜/雾/枯黄/封冻),不靠读者猜?("魔兽山脉白了头"必须交代是初雪还是早霜还是山雾)

## 二、事物/实物描写

### 1. 结点与铰连(物品参与情节,不是装饰)

- 经典小说里的物,是情节的"结点"(道具承担转折)与"铰连"(道具连起人与人的关系):眠鞋、钗、桃花扇——物在,情就在,物毁,缘就断
- 写作时先问:这件物在情节里"转"了什么?没有转动的物,不值得写
- 物品的传递=关系的传递(赠物/遗物/抢物/还物),每一次易手都是一次剧情齿轮

### 2. 质感体积(触觉优先)

- 写物的质感:重量(沉手/轻飘)、温度(烫/凉/贴肉生暖)、触感(糙/滑/涩/韧)、声音(磕碰/断裂/入鞘)
- 体积感:物在手里的大小、在房间里的占比——写"物"先写"物占了多少空间"

### 3. 功能与来历(为什么在)

- 每件物有三问:谁用它?从哪来?坏过没有?
- 来历即伏笔:一件旧物背后有一桩旧事,物是往事的实体
- 物的破损/修补=人物命运的镜像(缺口/补丁/包浆)

### 4. 具象先于象征

- 禁纯象征(先给物贴意义再写形)。先让读者摸到这件物,意义自然浮出
- 象征藏在具象里:不写"这剑象征她的仇恨",写"剑柄的缠绳换过七次,每次都是她亲手缠的"

### 5. 器物与人物关系

- 物怎么被用=人怎么活:用物的手(茧/颤/稳)、用物的动作(珍惜/随手/砸)、物的磨损处(哪处最旧,哪处就是这个人最常碰的)
- 同一件物在不同人手里,写法不同——物是人的延伸

## 三、食物/美食描写

### 1. 五感联动(色香昧触声)

- 色:热气/油光/汤色/食材本色
- 香:烟火气/辛香/甜香/焦香(香是勾人的,先于味)
- 味:咸淡/回甘/层次(味要写"变化",不写"好吃")
- 触:烫/糯/脆/滑/韧(口感即节奏)
- 声:沸/炸/吸溜/咀嚼/吞咽
- 规则:写吃的段落,至少三感在场

### 2. 把食物写成有故事的主角(汪曾祺式)

- 汪曾祺写高邮鸭蛋:"筷子头一扎下去,吱——红油就冒出来了。"一个"吱"+一个冒油,五十年后读者还记得
- 方法:给食物一个"记忆点动作"(扎/掰/咬/撕的瞬间),让这个动作成为这段文字的锚
- 食物可以成为章节的情绪主角:一碗面是家的实体,一顿饭是关系的战场

### 3. 家常话烟火气(禁精致堆砌)

- 禁西餐摆盘式描写(精美餐具/烛光/摆盘术语堆砌)= 高级感陷阱,读者无感
- 写市井/家常食物用家常话:锅气、油星、烫手、吸溜——朴素词才有烟火气
- 美食的"好吃"不写形容词,写身体反应:烫得吸凉气/咸得皱眉/鲜得停不下筷

### 4. 吃相即性格

- 同席者怎么吃=各自是谁:狼吞(饿/急/身份低)、细品(讲究/贵/装)、只吃不语(心事)、布菜给别人(照顾/上位)
- 分食/让食/抢食=关系的微缩戏
- 食毕的残局:碗底剩什么、桌上乱不乱——都是人物状态的收尾

### 5. 食物与记忆/情感

- 味道唤起(普鲁斯特效应):一口旧味=一段旧事,味道是穿越时间的钥匙
- 禁:"这味道让她想起了家乡"直白点题;要写"她顿了一下,筷子停在半空"这种身体反应

## 四、动物描写

### 1. 外形:整体到局部,突出最有特征的部位

- 先轮廓(大小/毛色/体态),再落最有特征的部位(鹰的翅、猫的眼、狗的鼻)——只写特征部位,不逐项罗列
- 特征部位=这个动物性格的物理入口(老猫浑浊的眼=迟暮)

### 2. 习性即性格

- 动物的行为模式就是它的"人设":白公鹅走路傲慢(步态=性格)、老舍的猫(又乖又闹的矛盾=活)
- 写习性不写标签:不写"这狗很凶",写"它见生人,先不叫,蹲下,尾巴慢慢竖起来"
- 动物的"理"与人的"理"一样要成立(护食/护崽/地盘/恐惧)

### 3. 动态与动作细节

- 动作的起承转合:扑/退/僵/抖,肌肉与毛发的反应(炸毛/贴耳/露齿/摇尾)
- 捕猎/进食/对峙/亲近,四个场景各写透一次,动物就立住了
- 禁:动物只会"叫"和"跑",要有属于该物种的动作细节(猫舔爪、狗绕圈、马喷鼻)

### 4. 拟人但有物种边界

- 可以拟人(通人性),但保留动物的物理边界:它不理解人话的全部含义,它的行为有自己的逻辑
- 最好的动物写法是"半懂":它察觉主人的情绪,但用动物的方式回应(蹭/躲/叼东西来)
- 禁:把动物写成穿毛皮的人(会说话会思考像人一样)——除非这是设定本身(灵宠/妖物,那走世界观规则)

### 5. 动物与人物关系

- 工具(战马/猎鹰)、伙伴(陪/救/背叛)、镜像(人物的动物性投射:驯兽者与被驯者)
- 动物对人物的态度=人物性格的第三方佐证(恶人对狗也恶,温人对牲畜也温)
- 动物的生死可以是剧情刻度(马死=退路断,猫失踪=家散)

## 五、人物描写八维(被看见的那一瞬,按需选维)

> 这是 02-character.md 七维度的"描写层"细化。人物出场/再出场,从八维中选 2-4 维落笔,不八维全写(全写=人物卡)。越重要的瞬间,选越少的维度写透。

### 1. 长相(脸面五官)

- 脸型/眉眼/鼻/唇/肤色/疤痕/皱纹——写 1-2 处传神部位,禁五官全列
- 长相随年龄/遭遇变(眼窝陷、颧骨突、笑纹深),长相是人物历史的皮肤
- 禁"她长得很美"式概括,写"她的美"具体落在哪(眉?颈?还是气色)

### 2. 体态(整体形貌)

- 高矮/胖瘦/骨架/肉感/筋络——先定"这人占多大体积"
- 体态是阶级与职业的刻痕(常年劳作的手粗脚宽、久坐的文士肩塌背驼)

### 3. 身段(形体线条)

- 肩线/腰线/腿长/曲线——多用于成年向/感情线场景,写"动起来的样子"而非静止身材
- 身段要在动作里显(行走/倚靠/弯腰),禁静态陈列

### 4. 身姿(站走坐的架式)

- 站相/走相/坐相/落座起身的幅度——身姿即气质的外壳
- 身姿随心境变:得意时脊背直、受辱时肩缩、戒备时重心前倾
- 身姿是体面感的物理层(先有护体面的挺直,才有之后的崩塌,见 02-character 活人化)

### 5. 服饰(衣/鞋/头巾/披挂)

- 材质/颜色/新旧/破损/打理程度——衣饰即处境(见 02-character 写人四法第四法)
- 衣随事变:同一人换衣=状态切换(换新衣=新生,衣破=败落,衣不解带=警惕)
- 禁"穿着华丽的衣服"式标签,写"领口的绣线磨秃了,袖口挽着,露出腕上一圈旧伤"

### 6. 首饰(佩/簪/环/佩玉/法器)

- 材质/来历/戴法/是否贴身——首饰是人物关系的实物(信物/家传/身份标识)
- 首饰的摘与戴都是戏:摘下来=卸下身份,戴上去=回到位置
- 玄幻/仙侠:首饰可兼法器,功能即性格(护身/攻/藏)——但要见物见人,禁纯道具说明

### 7. 表情(面部神情)

- 微表情优先(眉动/眼睑/嘴角/鼻翼),禁大表情标签("他震惊地瞪大了眼睛")
- 表情的变化过程比结果重要:先僵→再垂眼→最后扯出一个笑=一段完整心理
- 表情与内心可相反(脸上笑着,眼是冷的)——反差即张力

### 8. 动作(身体语言)

- 小动作/习惯动作(捻衣角/敲指节/舔唇)——习惯动作即人物指纹,贯穿全书(见 02-character 细节闭环)
- 动作节奏:快动作(扑/抢/砸)与慢动作(抬手/放下/转身)交替,节奏即情绪
- 禁"他高兴地跳起来"式动作+情绪双标签,动作自己说话

### 八维速查

| 维度 | 核心一问 | 一句话技法 |
|---|---|---|
| 长相 | 哪一处传神? | 写1-2处,禁全列 |
| 体态 | 占多大体积? | 高矮胖瘦定轮廓 |
| 身段 | 动起来怎样? | 在动作里显线 |
| 身姿 | 架式是什么? | 站走坐即气质 |
| 服饰 | 处境怎么样? | 新旧破损即命运 |
| 首饰 | 关系是什么? | 戴摘皆是戏 |
| 表情 | 变化过程呢? | 过程优于结果 |
| 动作 | 指纹是什么? | 习惯动作贯穿 |

## 六、生活描写(吃喝拉撒睡/性交/偷窥/意淫)

> 生活是活人的地基。人物不是只在剧情节点活着,是在吃饭睡觉拉屎里活着。生活细节写足了,人物才不是道具。

### 1. 吃喝拉撒睡(日常五维具象,拒绝升华)

- 空间维:人在哪吃睡拉(灶房/炕/檐下/茅房)——空间即阶层
- 关系维:和谁一起吃睡(独食/分食/同榻/守夜)——关系在生活里显形
- 经济维:吃什么档次/用得起什么(粗粮/细粮/油盐多少)——账本即处境
- 身体维:吃相/睡姿/起夜/排泄的身体细节(健康/病痛/岁月痕迹)
- 时间维:一日的循环(何时起/何时睡/何时饿)——时间表即生存状态
- 铁律:生活场景不升华。写吃喝拉撒就是写吃喝拉撒,不强行拔高成"生活的诗意"——烟火气本身就够。禁"一碗粥里盛着人生的况味"式感叹
- 生活细节服务于:人物状态(饿/病/累)、关系变化(分食到同食)、时代质感(物资水平)

### 2. 性交(成人向必读 05b-sex-scenes.md)

- 本 skill 的性场景完整规格在 references/05b-sex-scenes.md(必写清单/觉醒链三阶/非自愿处理/直白词规则),本文件只列维度原则
- 维度原则:身体的(生理反应链)、心理的(欲望/恐惧/恨/爱混杂)、关系的(权力位次在床上的显形)、空间的(场所/声响/隔音,物理闭环)
- 尺度路由:受众尺度决定写多直白;非自愿场景必须同时读 05-sensitive.md
- 禁:为写而写(无剧情功能的性段落)、美化非自愿、替代词(用直白词,见 05b)

### 3. 偷窥(视角边界戏)

- 偷窥是视角的天然舞台:看的人限知(只看见局部/听见片段)、被看的人不知——信息差即张力
- 写看的人:看的动作(屏息/贴窗/扒缝/不敢眨眼)、身体的紧张(冷汗/腿软/心跳)、看的代价(被发现的风险时刻)
- 写被看的一面:只写看得见的部分(身形/剪影/半张脸/一声喘),看不见的留给读者
- 禁:偷窥段落变全知(偷窥者不可能知道被看者的全部心理)——保持限知,读者比偷窥者多知道一点点即可
- 偷窥的道德重量:看的人内心冲突(不该看/忍不住/看完的罪疚),这是人物弧线的材料

### 4. 意淫(内心镜像戏)

- 意淫=欲望的内心镜像:想什么、怎么想、想到什么程度(一闪念/深想/自我说服/掐断)
- 写意淫不写结论,写过程:从哪一点被勾起(一个动作/一句词/一截皮肤)→想象如何展开→如何自我打断(羞愧/理智/更深的欲)
- 意淫暴露:欲望对象的选择=人物价值观;意淫的方式=人物的自控与道德
- 禁:把意淫写成旁白抒情("她心里涌起一阵说不清的悸动"=禁词+标签化);要写具体的想象画面与身体反应
- 意淫与现实的落差是戏:想了十分,做到三分;或现实比想象更狠——落差即剧情

## 七、房屋建筑描写(宅院/屋舍/宫殿/楼阁/宗门建筑)

> 建筑是"立起来的处境":人住什么屋,就是过什么日子。建筑维度拆解见下表,与"五、人物八维·服饰"同理——建筑的形制/新旧/破损即主人的阶层与命运。

### 1. 结构骨架(建筑怎么立起来)

- 梁柱/墙体/屋顶/地基/台阶——先写承重与轮廓,建筑才"立得住"
- 结构即年代与财力:粗木巨柱=老派大户,砖包土墙=中产,茅草竹篱=赤贫;飞檐斗拱=官,歇山重檐=殿,硬山青瓦=民
- 禁:只写"一座大宅"标签,不写它是怎么盖的、用什么盖的

### 2. 空间格局(动线即秩序)

- 间数/进深/院落/廊道/楼梯——先给空间比例,再写人怎么走(动线)
- 空间即权力:正房朝南给谁住、厢房给谁、下人房在哪、灶房挨着谁——一个家的格局就是一张权力图
- 禁:户型图式罗列(东屋西屋北屋各一间平铺=平面图,无人在其中走动)

### 3. 采光通风(光即地位)

- 门窗朝向/天井/亮暗/风路——光分到哪,地位就在哪:正房亮堂,偏房阴湿,地下暗室无光
- 采光变化=时间与情绪:日影进屋的移动、午后昏黄的室内、夜里一灯如豆
- 建筑的光线是"藏在屋里的人"的光线:亮=有人气,暗=藏事/败落/囚禁

### 4. 陈设布置(物即主人)

- 家具器物/帷帐/匾额/香火/字画——陈设暴露主人的趣味、经济与心事
- 禁"富丽堂皇"式标签,写具体:太师椅的包浆、供桌上积灰的香炉、墙上斜挂的旧画
- 陈设随事件变:翻倒的桌椅=打斗过,蒙尘的嫁妆=死过人,空了的书架=被抄过

### 5. 岁月痕迹(旧处即故事)

- 磨损/修补/尘/蛛网/包浆/裂缝——建筑的旧处是时间的实体,也是往事的实体
- 门槛磨凹=出入的人多,补过的梁=塌过一次,墙上的刻痕=谁在这长过
- 破损与修补=家族命运的镜像(与"二、事物·破损即命运"同律,建筑是放大的器物)

### 6. 声气氛围(建筑的气场)

- 声音:脚步声的回响/门轴的吱呀/梁上的鼠/檐下的雀/夜里的风过窗纸
- 气味:木香/霉味/烟火气/香火/土腥——气味即这栋屋的"人气"
- 温度与潮气:冬暖夏凉的堂屋 vs 阴冷潮湿的偏房——体感即处境

### 7. 风水与势(玄幻/异世界:建筑即规则)

- 玄幻/仙侠/古典:建筑选址/朝向/格局可暗合风水或宗门"势"(龙脉/灵气走向/阵法节点)
- 宗门建筑:山门/大殿/藏经阁/禁地/演武场——每处建筑是一个功能,也是宗门秩序的空间化
- 阵法/禁制/护山大阵:建筑承载的力量体系显形(禁地为何是禁地,不是牌子写的,是阵守的)
- 禁:把玄幻建筑写成现代平面图+贴个阵法标签;阵要能感觉到(威压/温度/光),不是报菜名

### 8. 检查要点

- [ ] 建筑暴露了主人的阶层/处境/性格(形制/材质/新旧)?
- [ ] 有空间格局与动线(人在其中走动),非户型图罗列?
- [ ] 从 7 维中选了 2-4 维写透(结构/空间/采光/陈设/痕迹/声气/风水)?
- [ ] 建筑承担了剧情功能(空间即权力/门是戏眼/兴衰即家族)?
- [ ] 玄幻/异世界:有"只有这个世界才长得出"的建筑元素(阵法/禁制/灵材/宗门之势)?
