# 读者反馈与Beta阅读(19)——让外部眼睛帮你看

> 处理"找外部读者/模拟读者反应/整合反馈"的规格。**何时读**:结构修订后、定稿前(找真人Beta读者);无真人时(用模拟读者视角自检)。
> 定位:作者看自己的稿子永远有盲区——冷却期(14)是"自己冷下来看",本规格是"让别人看+模拟别人看"。

## 一、为什么需要Beta读者

- 作者读自己的稿子:脑补了没写的内容(以为写了其实没有)
- 外部读者:只读到你写的字——他们读到的,才是读者会读到的
- 至少2位读者:不同口味互补(一个看剧情/一个看文字)

## 二、找什么样的Beta读者

- 目标读者群的人(你写给谁就找谁)
- 会反馈的人(不是"很好"就完事)
- 不同背景(同行+普通读者各一)
- 铁律:不要只找家人朋友(怕伤感情不说真话)

## 三、给Beta读者的提问(别问"好看吗",问具体)

- **情节**:哪里读不下去/想跳?哪里没看懂?
- **人物**:谁喜欢谁讨厌?哪个角色立不住?
- **节奏**:哪里慢哪里快?哪章想弃?
- **开头**:前三章想不想继续?为什么?
- **结尾**:结局满意吗?承诺兑现了吗?
- **情绪**:哪段被打动?哪段无感?
- **具体问题**:问你想确认的点(如"这个伏笔明显吗?")

## 四、无真人读者时的"模拟读者"自检

- **第一遍(读者视角)**:只读,不分析——标记"走神/疑惑/想跳"的地方
- **第二遍(目标读者模拟)**:想象你是目标读者(男频爽点党/女频情感党),哪里爽/哪里闷?
- **第三遍(冷读者)**:假装没看过设定,哪里看不懂?
- 产出:模拟读者笔记(和真Beta同样的问题清单)

## 五、整合反馈(不是全盘接受)

- 分类:结构问题(改)/个人偏好(可忽略)/误解(说明或改清)
- 规则:
  - 2个读者都指出的问题 = 必改
  - 1个指出的 = 判断(是否目标读者/是否有理)
  - "好看但说不出哪好" = 可能结构有大问题(他感觉不对但说不出)
- 铁律:读者指出"哪里有问题"往往对,但"怎么改"不一定对——你自己决定怎么改

## 六、完稿自查

- [ ] 找Beta读者了吗?(≥2位,目标读者优先)
- [ ] 问的是具体问题(非"好看吗")?
- [ ] 反馈分类了吗?(结构/偏好/误解)
- [ ] 2人都指出的问题改了吗?
- [ ] 无真人时,做了三遍模拟读者自检吗?

## 七、与其他规格的关系

- 修订 → 14-revision(Beta阅读在结构修订后/定稿前)
- 模拟读者 → 02-character(以目标读者心态读)
- 市场 → 15-market-research(目标读者是谁,反馈才有参照)
