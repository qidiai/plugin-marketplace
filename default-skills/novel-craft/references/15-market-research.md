# 市场调研与题材定位(15)——开书前的"选赛道"

> 处理"写什么题材/写给谁/发哪个平台"的规格。**何时读**:访谈完成、动笔前——尤其网文/商业化作品。纯文学/自娱可跳过(按内心写)。
> 定位:00-interview 问"写什么书",本规格问"写给谁、发哪、赚不赚"——网文圈共识:选品类比写作更重要。

## 一、开书前五问(市场定位)

1. **目标读者是谁?**(男频/女频/年龄/口味) → 决定题材/文风/节奏
2. **题材热不热?**(当前流行 vs 已过气 vs 小众蓝海) → 决定选题
3. **发哪个平台?**(起点/番茄/晋江/七猫…) → 决定门槛/节奏/尺度(对照17-platform)
4. **竞品有哪些?**(同题材在写什么/为什么火/为什么扑) → 决定差异化
5. **我能写多久?**(更新节奏/存稿能力) → 决定篇幅/日更目标

## 二、题材热度判断(2026参考,会变,写作时自查)

- **男频热门**:都市重生/系统流/玄幻升级/末日求生/仙侠凡人流
- **女频热门**:古言/宅斗/甜宠/快穿/重生逆袭
- **蓝海机会**:热门题材的"交叉/反套路"(如"系统流+经营""宫斗+悬疑")
- **判断法**:扫目标平台新书榜/签约榜——看头部题材+看上升中的新类型
- 铁律:不是"什么火写什么",是"什么火+我能写好"——选你擅长的热题材

## 三、差异化定位(避开红海)

- 同题材里,我的**独特点**是什么?(设定/主角/角度/写法)
- 一句话差异化:如"同样是重生,别人复仇我搞事业"
- 自查:这个差异化,读者在简介里能一眼看到吗?

## 四、读者画像(写给谁决定了怎么写)

| 维度 | 自问 |
|---|---|
| 读者性别/年龄 | 男频重升级爽感/女频重情感关系 |
| 阅读场景 | 通勤碎片(短章快节奏)/睡前沉浸(长章慢热) |
| 付费意愿 | 付费平台(要留人付费)/免费平台(要完读率) |
| 期待什么 | 爽点/情感/悬念/知识(按题材) |

## 五、竞品拆解(写前看三本对标)

- 读 3 本同题材头部书:
  - 它的**钩子**是什么?开头怎么抓人?
  - 它的**节奏**多快?(几章一个爽点/高潮)
  - 它的**人设**有什么读者买账?
  - 它哪里"读者想看的没写到"?(=你的机会)
- 产出:竞品笔记(钩子/节奏/人设/缺口)

## 六、市场定位输出(写入大纲/项目档案)

- 一段话:写给[谁]的[题材]小说,发[平台],主打[爽点/情感/悬念],差异化在[独特点]
- 对照:访谈(00)的题材/主角/冲突是否匹配市场?不匹配就调

## 七、完稿自查(开书前)

- [ ] 目标读者画像清楚了吗?
- [ ] 题材是热+我擅长的吗?(不是单热/单擅长)
- [ ] 差异化一句话说得清吗?
- [ ] 目标平台门槛/节奏了解了吗?(对照17)
- [ ] 竞品缺口找到了吗?(读者想看没写到的地方)

## 八、与其他规格的关系

- 访谈 → 00-interview(题材/主角/冲突)
- 平台门槛 → 17-platform
- 黄金三章(签约生死线) → 16-golden-three
- 爽点设计 → 08-hook-payoff
- 更新节奏 → 21-update-cadence
