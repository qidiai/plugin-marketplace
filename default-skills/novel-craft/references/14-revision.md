# 修订与编辑(14)——完稿后的加工层

> 处理"写完怎么改"的规格。**何时读**:初稿完成后、定稿前必读;作品要发布时必读。写作循环产出"初稿",本规格把它加工成"可发布稿"。
> 定位:写作循环(04)管"写出",本规格管"改好"——专业流程中修订占工作量60%+。

## 一、修订五层(从大到小,逐层过)

> 顺序不可乱:先修结构,再修内容,再修句子,最后修字。跳过结构直接改字=白改。

| 层 | 粒度 | 关注点 | 产出 |
|---|---|---|---|
| 1. **结构修订** | 全书/卷 | 章节顺序对不对?每章是否推进主线?人物弧线是否完整?有没有写废的章节? | 章节重排/增删 |
| 2. **内容修订** | 章/场 | 每场戏是否必要?过渡是否自然?逻辑漏洞?伏笔是否埋/收? | 场景改写 |
| 3. **行级修订** | 段/句 | 每句是否值得存在?声音一致性?重复啰嗦?节奏(短长句)是否贴场景? | 句子打磨 |
| 4. **文字编辑** | 词/句 | 语法/标点/用词准确/风格统一(禁词/腔调) | 语法修正 |
| 5. **校对** | 排版稿 | 错别字/格式/标点/章节编号 | 可发布稿 |

**铁律**:五层逐层过,每层只改本层的问题——改结构时不动句子,改句子时不动结构。

## 二、冷却期(专业流程关键,最容易忽略)

- **初稿完成后,至少冷却 2 周再开始修订**——让初稿的"作者情绪"消退,用读者眼光重读
- 冷却期间:读别的书/写别的短篇/完全不碰稿子
- 冷却后重读:标记"哪里读不下去/哪里走神/哪里奇怪"——这些是结构问题的信号
- 短篇可缩短(1-3天),长篇必须足量(2周+)

## 三、结构修订(第一层,最重)

- **通读一遍,不改**——只标记:章节顺序/节奏/弧线/废章
- 问:
  - 每章是否推进主线?(删"没推进"的章或并)
  - 人物弧线是否完整?(起点→转折→终点)
  - 开篇三章是否抓人?(对照黄金三章规格)
  - 结局是否兑现开篇的承诺?(钩子/伏笔回收)
  - 有没有"为写而写"的章节?(氛围章/设定章,删)
- 产出:章节重排清单 / 需新增的章 / 需删除的章

## 四、内容修订(第二层)

- **逐章逐场过**:每场戏的"功能"是什么?(推进/塑造/铺垫/爆发)——没有功能的场删
- 检查:
  - 过渡:场景切换是否自然?(用动作/时间/环境交代)
  - 逻辑:时间线/年龄/事件顺序/人物状态是否一致(对照记忆系统)
  - 伏笔:埋的收了吗?台账勾销了吗?
  - 对话:每个人物的腔调是否一致?对话是否推剧情?
  - 信息:有没有"作者知道但人物不该知道"的泄露?
- 产出:每章的修改清单(改什么/为什么)

## 五、行级修订(第三层)

- **逐段逐句**:每句是否值得存在?删掉后读感更好吗?
- 检查:
  - 重复:同一意思写两遍?同一词高频出现?
  - 啰嗦:能短则短(删"的/了/是")
  - 声音:句子节奏是否贴场景?(紧张=短句/舒缓=长句)
  - 对话:是否书面化?(改口语/语气词/打断)
  - 禁词:对照反AI规格(04)和本书禁词表
- 技巧:朗读——读出声能发现"读不下去"的句子

## 六、文字编辑(第四层)

- 语法/标点/用词:错误修正
- 风格统一:腔调/感官偏好/比喻密度是否全书一致
- 一致性:人名/地名/称谓/时间是否前后统一(对照记忆系统)
- 方言/口语:是否贴人物(不是作者腔)

## 七、校对(第五层)

- 错别字/漏字/多字(用脚本+人工双查)
- 标点规范(中文标点/引号配对/省略号)
- 格式统一(章节标题/段落/空行)
- 章节编号/页码/目录

## 八、修订完稿自查

- [ ] 五层修订都过了?(结构→内容→行→文字→校对)
- [ ] 冷却期执行了吗?(短篇1-3天/长篇2周+)
- [ ] 结构层:每章推进主线?弧线完整?
- [ ] 内容层:逻辑/伏笔/对话/腔调一致?
- [ ] 行级:每句值得存在?无重复啰嗦?
- [ ] 文字层:语法/标点/风格统一?
- [ ] 校对层:错别字/格式干净?

## 九、与其他规格的关系

- 初稿写作 → 写作循环(00b草稿→正文)
- 修订前 → 冷却期(本规格)
- 修订中对照 → 记忆系统(时间线/弧线/伏笔台账/爽点台账)
- 修订后 → 09-export(导出/发布) + 17-platform(平台适配)
- 找外部反馈 → 19-reader-feedback(Beta reader)
