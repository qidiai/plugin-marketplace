# 完稿导出与发布(09)——定稿后的加工与发布

> 处理"全稿合辑/修订/校对/投稿/平台适配"的规格。**何时读**:初稿全部完成后、准备发布时。
> 流程:初稿 → 修订(14) → Beta阅读(19) → 校对(14) → 投稿材料(20) → 平台适配(17) → 导出(本节)。

## 〇、发布前完整流程(按顺序)

1. **冷却期+修订**:初稿完成后冷却2周+,按 14-revision 五层修订(结构→内容→行→文字→校对)
2. **Beta阅读**:找≥2位外部读者反馈,整合(19-reader-feedback)
3. **投稿材料**:书名/简介/封面/标签/synopsis(20-pitch-materials)
4. **平台选择**:查目标平台门槛/版权/AI边界/敏感词(17-platform)
5. **存稿评估**:连载要存稿+更新排期(21-update-cadence)
6. **导出**:本节格式合并

## 一、全稿合辑

- 合并所有章节 → final.md
- 每章标题格式统一
- 剔除作者注/草稿标记
- 校对(错别字/标点/格式)在修订层已做,导出前再跑一遍脚本

## 二、平台格式适配

| 平台 | 格式要求 |
|---|---|
| 起点/番茄/纵横 | 章末留钩子,分卷清晰,敏感词合规(对照17-platform) |
| 晋江 | 情感细腻,节奏适中 |
| 知乎/豆瓣 | 短篇/中篇为主,强观点 |
| txt/epub | 纯文本/电子书格式 |

- 敏感词检测:发布前跑目标平台敏感词工具,不适配处改写
- 错别字/标点/语法修正(14-revision 校对层)

## 三、导出命令

```bash
# txt 合辑(UTF-8无BOM)
cat chapters/*.md > final.txt

# epub
pandoc chapters/*.md -o final.epub --metadata title="{书名}"

# docx
pandoc chapters/*.md -o final.docx
```

## 四、完稿自查(发布)

- [ ] Beta读者反馈整合了吗?(19)
- [ ] 书名/简介/封面/标签准备好了吗?(20)
- [ ] 目标平台门槛/版权/AI边界/敏感词查了吗?(17)
- [ ] 连载的话,存稿/更新排期定了吗?(21)
- [ ] 全稿合辑无遗漏章节?
- [ ] 敏感词已适配目标平台?
- [ ] 错别字/标点已修正?
- [ ] 格式符合平台规范?
