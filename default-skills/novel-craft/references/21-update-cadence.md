# 存稿与更新节奏(21)——网文连载的"体力活管理"

> 处理"日更多少/存稿多少/何时上架"的规格。**何时读**:作品签约/决定连载时——网文是持续更新的生意,节奏管理决定能不能写下去。
> 定位:创作是脑力活,连载是"脑力+体力+管理"——本规格管体力与节奏。

## 一、日更目标(行业参考,按能力调整)

| 类型 | 日更字数 | 说明 |
|---|---|---|
| 全职网文 | 4000-6000 | 起点/七猫标准 |
| 兼职网文 | 2000-3000 | 番茄下限 |
| 女频(晋江) | 3000 | 重质量轻数量 |

- 铁律:定一个**可持续**的目标(不是爆发式)——断更是读者流失头号原因

## 二、存稿管理(签约后的安全垫)

- **签约/上架前**:存稿20-30万字(行业标准,防断更/防突发)
- **连载期**:保持存稿≥1周(约1-3万字),突发时能顶住
- **存稿≠草稿**:存稿是"已修订到可发布"的稿,不是初稿堆
- 自查:今天存稿还剩几章?够顶一周吗?

## 三、上架时机

- **付费平台(起点等)**:存稿达标 + 追读数据支撑(读者黏性够)
- **免费平台(番茄等)**:过签约线(2万字)即可,越早越好
- **信号**:追读率/完读率上升、评论区活跃、有核心读者群
- 铁律:上架前存稿必须足(上架=付费门槛,断更惩罚更重)

## 四、更新排期

- **固定时间更**(读者养成习惯):如每晚8点/每天中午
- **爆更策略**:周末/推荐期/冲榜期加更(需存稿支撑)
- **请假/断更**:提前公告+补更承诺(别无声消失)
- 自查:我的更新时间稳定吗?读者知道几点能等到吗?

## 五、数据与调整

- **追读率**(免费平台核心):掉=节奏闷/钩子弱 → 加爽点/加快节奏
- **完读率**:开头流失=黄金三章问题 → 重写开头(对照16)
- **评论反馈**:读者骂点=改进信号(对照19)
- 铁律:数据是读者的投票——掉数据就调,别硬扛

## 六、完稿自查(连载期)

- [ ] 日更目标可持续吗?(不是爆发式)
- [ ] 存稿≥1周吗?(签约前20-30万字?)
- [ ] 更新时间固定吗?
- [ ] 上架时机到了吗?(存稿+数据支撑)
- [ ] 数据掉了吗?知道为什么吗?
