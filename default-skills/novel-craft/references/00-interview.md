# 访谈脚本(第一层:问清写什么书)

> 每本书第一次使用时必读。目的:动笔前问清作者要写什么书,禁止跳过、禁止脑补。作者答了才往下走。

## 访谈规则

1. **一次问一层**:Layer1 必答问完 → 确认 → Layer2 → Layer3,不一次性全抛
2. **作者答了才往下**:每个问题至少等作者回答,不自己填
3. **答案记入项目档案**:访谈结果写入项目资料(风格指南/大纲/角色卡),后续沿用
4. **作者跳答可跟**:作者主动多说了就直接记,不打断
5. **作者说"随便/你定"时**:给2-3个选项让作者选,选不出才用最稳妥默认,并说明

---

## Layer 1 · 必答(3问,问清故事核心)

### 1. 题材类型?
- 玄幻 / 武侠 / 都市 / 悬疑 / 言情 / 历史 / 科幻 / 恐怖 / 网文(流派细分:系统流/赘婿/女频/男频)...
- 提示:这决定世界观文件(06)要不要读、爽点模块(08)要不要用

### 2. 主角设定?
- 姓名 / 年龄 / 身份 / 性格底色 / 目标 / 最想要什么 / 最怕什么
- 提示:主角是视角锚点,写谁就是谁的视角从这里定

### 3. 核心冲突?
- 主角要什么,什么挡着(外部对手/内部矛盾/环境)
- 一句话说清"这是个什么故事"

---

## Layer 2 · 深定制(可选但强烈建议,问清写作参数)

### 4. 世界观?
- 原创 / 同人(有原著?哪部?) / 半原创
- 力量体系(有无修炼/魔法/科技?)——有则需世界设定文件

### 4.5 市场定位?(网文/商业化作品必问,纯文学可跳)
- 写给谁?(男频/女频/年龄/口味)
- 发哪个平台?(起点/番茄/晋江/七猫…)——决定门槛/节奏/尺度
- 题材热不热?差异化在哪?
- 提示:答案写入 15-market-research 的市场定位输出;纯文学自娱可跳过

### 5. 叙事视角?
- 第一人称 / 第三人称限知 / 全知 / 多视角轮转
- 提示:决定视角铁律(01-pov.md)怎么执行

### 6. 基调?
- 爽文(主角一路变强) / 虐文(命运碾压) / 治愈 / 沉重 / 冷峻 / 诙谐

### 7. 受众尺度?(关键,决定敏感场景路由)
- 全年龄(无性描写/无过重暴力)
- 成人向(含性描写)→ 需读 05b-sex-scenes.md
- 黑暗向(非自愿/虐待/重暴力)→ 需读 05-sensitive.md + 05b

### 8. 章节规模?
- 短篇(1-10章)/ 中篇(10-50)/ 长篇(50+)/ 不确定

### 9. 写作风格?
- 文风基调(古风/现代/华丽/朴素/冷峻)
- 句长偏好(短句密集/长句绵长/长短交错)
- 叙事腔调(冷叙述/代入式/间离)
- 比喻策略(密集/克制/禁用)
- 方言/口语度
- 有范文?→ 可蒸馏作者文风
- 提示:答案写入 style-guide.md(风格独立资料文件)

---

## Layer 3 · 参考源(有才用)

### 10. 有没有原著/参考书/素材?
- 同人:哪部原著?必须读原著设定(角色/世界观/力量体系)
- 风格参照:哪本书/哪个作者?可蒸馏文风
- 素材:史料/新闻/真实案例?(写作时用)
- 无参考:跳过

---

## 访谈完成后

1. 向作者复述理解:"你要写的是[类型]小说,主角[名字],讲[冲突],尺度[全年龄/成人/黑暗],参考[有/无]"
2. 作者确认后 → 进入②资料拆分(00b-project-setup.md)
3. 若作者中途说"先写一章看看" → 可先写黄金三章(03-pacing.md),但资料拆分在3章内补完
