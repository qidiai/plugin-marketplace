# 暴力/创伤/非自愿场景(仅当作品涉及才读)

> 处理流血/虐待/尸体/非自愿/创伤后反应的规格。**只读此文件的时机**:作品含黑暗向内容(访谈Layer2受众尺度=黑暗向)或当前章节涉及此类场景。否则不读。

## 一、非自愿场景核心(红线)

- **身体背叛她**:身体反应(湿/叫/喷)与心理(恶心/羞耻/恨身体)并行。她恨身体。
- **禁美化**:禁"她享受了/欲拒还迎";禁"她湿了所以自愿"(湿是生理反射,与意志无关)。
- **禁施暴者洗白**:禁"他其实爱她/动情/心疼";只写冷酷/工具化。
- **禁把受害者写木头**:身体反应+心理崩塌必须并行。

## 二、创伤真实感

- **解离**:意识断片/飘走/延迟反应——"认不出床上那个女人"/"我真的不记得了"。可复用,不只用一次。
- **身体反应必接自我审判**:写了反应(尿/硬/流液/湿)必须写"怎么想自己"(恶心+控制不住+恨身体)。
- **事后沉默是状态**:说不出话/不想说话=语言中枢暂时关闭,别写成"她生气了"。
- **形体痕迹累积**:身体痕迹一层层加(每隔一两轮一个新伤),"用身体付账"靠累积不靠一次性清单。
- **生存逻辑**:长时间场景必须给生存条件(密室备水/干粮),禁"熬一夜还精神抖擞"。

## 三、形体曲线

被压垮的角色有"直立→蜷缩→再跪直"的形体弧线,中间写"撑回去"的动作(被压垮后撑着地慢慢跪起来)——性格的形体化。

## 四、一次性设定必有后遗症

工具型设定(药/刑具)用完不能丢,要有后遗症/后续影响。

## 五、完稿自查(涉及时)

- [ ] 非自愿:身体+心理并行,无美化?
- [ ] 施暴者零洗白零动情?
- [ ] 创伤反应真实(解离/沉默/延迟)?
- [ ] 身体痕迹累积,不是一次性清单?
- [ ] 事后有审判(怎么想自己)?
