# 节奏与起承转合(每章必读)

> 管"怎么讲"——节奏、结构、钩子、开篇。写完用本节自查。

## 一、七段式(章节级节奏模板)

```
缓铺打底(日常细节/安全假象) → 双线暗蓄(明线正常暗线潜伏) → 环境加压(景物逐级升级) → 空间锁闭(场景收缩退路封死) → 憋压延时(临近爆点刻意不爆) → 瞬间爆破(短句快叙动作连发) → 余韵缓收(不仓促收尾)
```

## 二、章末钩子4型(读者看最后三行决定翻不翻页)

1. **悬念式**:门外传来一个不可能出现在这里的人的声音
2. **反转式**:整章暗示A凶手,最后一行B手上有血
3. **情绪炸弹式**:三章矛盾章末爆发,直接切掉
4. **信息投放式**:日记本最后一页画着一张和自己一模一样的脸

钩子在蓝图里提前规划,不写完再想结尾。

## 三、快慢控制

- 紧张段落短句≤15字(加速);平静段落长句(减速)
- 高潮快写、过渡略写、铺垫慢写
- 铺垫最长不超2章;大爽点需5章铺垫则穿插小爽点

## 四、危险时刻禁内心戏

- 逃命/搏杀/被追只写身体(喉咙发甜/膝盖发软/脚下绊/不敢回头)
- 内心戏留给安全时刻;危险时刻的"想"只有一个——下一步往哪跑

## 五、环境是人的延伸

- 景物以人物"主观镜头"出现时打情绪印记:开心时枯草与阳光共舞,伤心时晚霞像漫天油污
- 环境当节拍器:风雪从小到大对应危机升级
- 写孤独靠声音(从前的呼噜声/添灯脚步/梦话,现在没了),不靠抒情

## 六、黄金三章(开篇抓人)

- **第1章**:立主角(他是谁/想要什么)+ 一个抓人的场景 + 埋全书钩子
- **第2章**:冲突升级 + 展示主角的性格(通过选择)+ 引入核心对手
- **第3章**:第一个小高潮/小爽点 + 章末钩子逼翻页
- 黄金三章内:读者要知道"这是谁的故事/要看什么/为什么看下去"

## 七、场景类型(起承转合)

- **主动场景**:目标→冲突→挫折(结果比预期更糟,推动情节)
- **被动场景**:反应→困境→决定(角色被上一场景击中后,做出选择)
- 每2-3个主动场景后插一个被动场景,给读者和角色喘息

## 八、空白页(重大事件后)

重大事件之后、下一事件之前,给一段完全静止(视角人物听不见/看不见/动不了/时间感断裂)——让上一事件落实,再切场。禁连环事件无缝叠。

## 九、情感投资配比

日常铺垫与暴力爆发体量必须匹配——爆发越重,前面的"家"越具体。写日常主动埋"家"的记忆(旧习惯/全家瞬间),读者情感账户够厚,崩塌才不是"惨"而是"亲手养大的东西碎了"。
