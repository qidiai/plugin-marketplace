# 人物描写(每章必读)

> 写人四法 + 人物七维度 + 活人化。每章主要人物出场,按此核对;完稿后按"人物一致性"复查。

## 一、写人四法

1. **传神在阿堵**:外貌只在"被看见"时写,人物卡式堆叠=死。神优先于形:一个能定住魂的动作/一眼目光/一个习惯,胜过十句形貌。
2. **动态白描**:性格全在动作,情绪标签是废字。写"她害怕"→写"指尖掐进砖缝,指甲断了半根也没觉得疼";写"他冷酷"→写"先抬眼把整个院子过了一遍秤"。
3. **不写满**:主要人物至少一处缺陷/私心,无纸片人。反派有他的"理",受害者有她的算计/软肋。
4. **衣饰即性格**:衣饰随处境变化,写衣饰要能看出住的人是谁。衣饰的"乱"就是命运的"乱"(发髻散落=体面崩塌)。

## 二、人物七维度(主要人物出场逐项核)

1. **形貌(身体在场感)**:眉眼神情/身段体态(衣料互动·叠词部位·动态)/穿着衣饰/气质之韵/年龄痕迹
2. **身份(社会坐标)**:姓名称呼/出身家世/修为能力(玄幻必交代:功法/境界/斗技)/地位财富/家庭角色——**地位展开规格见下方"社会地位(阶级坐标)"专节**
3. **性格(内在内核)**:核心动作口头禅(承载世界观)/习惯小动作(细节闭环)/缺陷私心/欲望与恐惧
4. **关系(人际网络)**:核心关系活互动(禁零直接对话)/相处细节/他人眼中的他
5. **背景(前史)**:前传关键必须在正文有记忆点,禁"后面才补"
6. **动态(变化轨迹)**:出场做点什么/处境困境/成长弧
7. **境遇(世界嵌入)**:玄幻日常纹理/家世与世界的接口

## 二点五、社会地位(阶级坐标)——身份维度的展开规格

> 地位不是一行设定,是一整套"能/不能"的规则:地位决定权力、穿着、财产、生活、行为边界、他人对待方式。**写角色先定地位,再写他的一切行为**——主母不会干下人的活,小姐不会抛头露面,下人走侧门不穿锦缎。地位错位=失真(大小姐劈柴/贵妇当街叫卖,除非剧情明确写地位崩塌)。**所有类型通用**(古典=官爵门第/现代=财富职业/玄幻=出身修为/武侠=辈分武功)。

### 0. 先定世界的阶级梯子(社会分层)

- 世界分几层?依据什么分?——按本书题材定:玄幻=修为段位+出身血统+家族;古典=官爵/门第/宗法;现代=财富/职业/学历;武侠=辈分/师门/世家;架空=按本书自设
- 每层写清:该层的权力/穿着/财产/生活/行为边界/他人称呼
- 社会流动规则:升/降的通道是什么(玄幻=修炼晋阶/家族荣辱,古典=科举/联姻,现代=创业/婚嫁,末日=物资积累)——**升降通道即剧情通道**

### 1. 地位五要素(定角色先定这五项)

| 要素 | 核心一问 | 落点 |
|---|---|---|
| **权力** | 能命令谁/被谁命令/话语权多大 | 当家的能调度管家佣人,不能指挥族中长辈;下人听令不行权——权力边界即地位边界 |
| **穿着** | 衣料/纹样/颜色/配饰的等级规则 | 锦缎vs麻布/斗气袍vs短褐/女奴暴露+身份标记——衣着即地位通行证,换衣=换地位 |
| **财产** | 身家/产业/日用档次 | 月钱/宅院/仆从/饮食规格——账本即处境,吃穿用度全由财产定 |
| **生活** | 起居/劳作边界/社交圈 | 当家夫人执笔理事不洒扫/小姐学规矩不劈柴/下人洗衣走侧门——**劳作边界是地位的硬边界** |
| **行为边界** | 这个身份做什么/不做什么 | 地位=行为禁区:越界即失体面(贵妇下厨=失礼)/招祸(下人穿主家衣=僭越) |

### 2. 地位在文本里怎么显形(五条)

- **他人对待**:称呼(夫人/大人/奴婢/贱奴)、态度(恭敬/无视/呵斥)、肢体距离——地位越高,旁人越先低头
- **空间权力**:住正房/厢房/下房;走正门/侧门/后门;坐主位/下首——空间即权力地图
- **劳作边界**:谁做粗活谁做细活谁不干活——地位决定手干什么活,手是地位的刻痕(当家夫人指腹薄茧=执笔理账,下人手掌粗茧=洒扫搬运)
- **穿着即处境**:衣料纹样是地位的通行证,衣随地位变(升=换新衣,降=衣破,被掳=囚服)——衣饰的乱=命运的乱
- **地位变化是剧情**:升(嫁入/晋阶/立功)降(抄家/被掳/流亡/失势)——地位崩塌即体面崩塌,是人物弧线的实体

### 3. 地位双线(各类型通用:生来的 × 练来的)

- 任何类型,地位都是**两条线**叠加,不可只写一条:
  - **生来的**(出身线):玄幻=家主/嫡女/主母/下人/女奴;古典=官爵/门第/嫡庶/宗法长幼;武侠=辈分/师门/世家;现代=财富/家族/学历出身;架空/科幻/末日=按本书自设的社会分层(见本节 0 步)
  - **练来的**(本事线):玄幻=修为段位(如"练气/筑基/金丹"或"斗者/斗师/大斗师");古典=科举功名/政绩;武侠=武功境界/江湖名望;现代=职业成就/社会资本;末日=物资/武力/组织地位
  - 两线可能一致(世家+功名)也可能冲突(寒门贵子/有本事的奴仆)——**冲突是戏**
- 通用铁律:实力(本事)高可压出身低(强者让贵妇低头);被掳/被囚/抄家时出身线崩塌,本事线可能还在=角色的暗手/翻身底牌
- 地位跌落时不只丢体面,丢的是**行为边界**——贵妇被迫干下人的活/卖身的活,每一件都是地位崩塌的实写

### 4. 检查清单(写完对照)

- [ ] 这个角色什么地位?能做什么不能做什么(劳作边界/行为禁区)?
- [ ] 穿着/财产/生活/他人称呼是否与地位匹配?
- [ ] 地位边界被尊重还是被打破?(打破=戏点,须有剧情原因)
- [ ] 生来的(出身线)×练来的(本事线)两条线都交代了吗?两者冲突了吗?
- [ ] 地位变化(升/降)是否带动了行为/穿着/待遇的变化?

## 三、活人化(写活,不写符号)

- **人物是活人不是角色**:穿衣服/吃东西/有七情六欲/会脏话/会矛盾
- **亲密关系活人化**:斯文人上/床的时候一样粗俗。白天端庄,床上会说脏话、会浪、会骂俏——两种状态都真(壳vs本声切换)
- **战斗人物血肉感**:武人出手写身体细节(青筋/厚茧/汗水/小臂),不只写"技能名+特效光效"或"招式名+光环"
- **体面崩塌有过程**:被压垮的角色先有"护体面"本能动作(拢头发/系衣襟/挺直腰),再崩塌——维持体面的本能动作本身就是人物弧线的一部分
- **身体恐惧靠动作**:恐惧时写具体小动作(握紧的手/发白的手指/渗血的指甲/僵住的呼吸),不贴"他害怕"标签

## 四、细节闭环

- **细节从铺垫到回收**是人物立住的证据(角色的护身符/旧物件:第一章出现→中期破损→后期回收,贯穿全书)
- **口头禅承载世界观**:一个反复出现的口头禅/习惯动作,在命运转折点语义翻转——"账,是从来对得上的"→被摧毁后"这笔账,我要算平"=拿命对账
- **配角铺垫锚**:重要配角登场章就埋习惯动作(某个小动作/口头禅),为后文铺垫——读者日后见他能想起"和当年那批人一路的"

## 五、群像

- **群像反应各异**:同一场景每人反应不同(眼睛直/咽口水/低笑/酒碗掉了),禁千人一面
- **通过他人视角塑造**:细节被另一个角色注意到=两重信息

## 六、人物一致性(完稿复查)

- [ ] 角色是否OOC?(行为/语气/口头禅是否符合设定卡)
- [ ] 角色修为/境界/功法是否与资料库一致?
- [ ] 角色年龄/身份/关系是否与时间线一致?
- [ ] 标志性细节是否贯穿(从铺垫到回收)?
