# 爽点设计(网文——仅当作品是网文/商业化才读)

> 处理爽点/期待-回报/打脸节奏的规格。**只读时机**:作品面向网文平台(起点/番茄/晋江等),需爽点设计。纯文学可跳过。

## 一、期待-回报循环

```
埋期待(读者想要X) → 延迟(不能马上给) → 回报(给X,且超预期) → 新期待
```

- 每个爽点=埋期待+延迟+超预期回报
- 延迟要有张力(憋压),回报要有落差(超预期)

## 二、爽点类型

1. **升级爽**:主角变强,境界突破——要有代价/过程,不是白给
2. **打脸爽**:反派轻视→主角反杀——打脸要够狠,反派要够可恨
3. **装逼爽**:主角藏拙→关键时暴露——装逼要有铺垫,暴露要震撼
4. **情感爽**:误解→揭晓→深情——情感要真,别为爽而爽
5. **夺宝/资源爽**:抢到好东西——有竞争/有风险

## 三、节奏排布

- 每章至少一个小爽点(网文节奏)
- 大爽点需5章铺垫则穿插小爽点,禁憋太久
- 期待-回报台账(hook-tracker.md):埋了哪些期待/该给哪些回报
- 禁:回报不到位(憋了不还)/回报太廉价(轻易给)

## 四、打脸三律

1. 反派要先立住(可恨),打脸才爽
2. 主角要占理(读者站主角这边)
3. 打脸结果要超反派预期(不止赢,是碾压式赢)

## 五、黄金三章与爽点

- 黄金三章内必须有第一个小爽点(让读者爽到)
- 第1章钩子+小爽,第2章冲突+小爽,第3章第一个高潮

- [ ] 爽点台账更新(埋了哪些/回报了哪些)?
- [ ] 打脸有铺垫有反差?
