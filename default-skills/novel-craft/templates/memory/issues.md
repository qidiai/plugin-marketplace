# issues.md · 待解决问题

> 写作中发现但未解决的事项追踪——剧情矛盾/伏笔未收/设定待定/读者反馈待改。**写前查此防遗漏**;解决后勾销。

## 待解决问题

| # | 问题 | 类型 | 发现于 | 待办 | 状态 |
|---|---|---|---|---|---|
| 1 | (例)第X章的时间与第Y章矛盾 | 时间线 | 第X章 | 核对时间线.md修正 | 未解决 |
| 2 | (例)某伏笔埋了未回收 | 伏笔 | 第X章 | 在伏笔台账登记 | 未解决 |
| 3 | (例)某设定待作者确认 | 设定待定 | 访谈/写作 | 问作者 | 未解决 |

## 类型

- **剧情矛盾**:时间线/人物状态/事件顺序冲突(跨章核对)
- **伏笔未收**:埋了没回收(联动伏笔台账)
- **设定待定**:作者未拍板/资料库没写(不能脑补)
- **读者反馈**:Beta读者指出未改(联动19-reader-feedback)
- **修订遗留**:修订时标记的待改点(联动14-revision)

## 维护规则

- 写作中发现"不对劲但说不清" → 记入 issues,继续写,回头查
- 每章完稿后 → 过一遍 issues,能解决的解决,勾销
- 定稿/发布前 → issues 必须清零(残留=未完成)

## 一致性检查

- [ ] 有未解决的剧情矛盾吗?(不能带着矛盾定稿)
- [ ] 伏笔台账有未收的吗?(联动伏笔台账)
- [ ] 有作者未拍板的设定吗?(不能脑补)
- [ ] Beta反馈都处理了吗?(联动19)
