## [1.0.0] - 2026-08

### Added / 新增

**流程（Pipeline）**
- 五层流程：①访谈 → ②资料拆分 → ③规格技法 → ④写作循环 → ⑤修订与发布（原为四层，新增"修订与发布"）
- 修订与发布完整链路：冷却期 → 五层修订 → Beta 阅读 → 校对 → 投稿材料 → 平台适配 → 存稿上架 → 导出

**规格文档（8 份新增，共 28 份）**
- `14-revision.md`：修订与编辑（冷却期 + 五层修订：结构→内容→行→文字→校对）
- `15-market-research.md`：市场调研与题材定位（目标读者/题材热度/差异化/竞品）
- `16-golden-three.md`：黄金三章（前300字钩子/三章分工/平台节奏差异/钩子三型/开篇禁忌）
- `17-platform.md`：平台适配与签约（门槛对比/版权避坑/AI边界/敏感词/上架运营）
- `18-story-structure.md`：故事结构模板库（三幕/Save the Cat15拍/英雄之旅/场景-续/Snowflake）
- `19-reader-feedback.md`：读者反馈与Beta阅读（找读者/提问清单/模拟读者自检/整合反馈）
- `20-pitch-materials.md`：投稿与发布材料（书名/简介/封面/标签/query letter/synopsis）
- `21-update-cadence.md`：存稿与更新节奏（日更目标/存稿管理/上架时机/数据调整）

**记忆系统（2 份新增模板）**
- `templates/memory/canon.md`：已确立事实（不随剧情漂移的定案，写前查防写岔）
- `templates/memory/issues.md`：待解决问题（剧情矛盾/伏笔未收/设定待定，解决后勾销）

**其他**
- `13-pitfalls.md`：避坑清单（群像戏份/视角跳切/威胁缺位/身体差异化/人物卡堆砌/对话禁词/跨章校验等 13 坑）
- 开源配套：`README.md`（中英双语）/ `CONTRIBUTING.md` / `LICENSE`（MIT）/ `CHANGELOG.md`
- 00-interview 新增"市场定位"问题（写给谁/发哪/题材热度）
- 00b 新增"流程按篇幅缩放"（短篇简化/长篇全套）

### Changed / 变更

- 流程从"四层"升级为"五层"（新增⑤修订与发布）
- `09-export.md` 从"直接导出"拆为完整发布流程（引用修订/Beta/投稿/平台/存稿规格）
- `05b-sex-scenes.md` 明确标注"成人向专用，仅当涉及"（防全年龄误读）
- 记忆系统目录新增 canon/issues（写前必读项更新）

### Fixed / 修复

- **通用性清理**：全 skill 项目专属词清零（人名/地名/功法/专有设定词）
  - `03b-style.md` 示例改为通用表述

  - `02-character.md` 社会地位示例通用化
